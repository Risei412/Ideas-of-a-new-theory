## シート1 — 【A1-1】次数つき盲点判定（主張B1）

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回
> **これが「還元成功」でも理論は死なない**（§4 の判定表を見よ）。土台の帰属先を確定するのが目的。

```
次の命題について、上記の手順で判定せよ。

【前提】
- 有限集合 Σ = {1,...,m}（m ≥ 2）を文字集合とする。
- 有限次元実ベクトル空間 V (dim V = n < ∞) 上の線形写像の族 {T_a}_{a∈Σ} を2組考える：
  {T_a} と {T'_a}。ただし {T'_a} は1文字 a=1 でのみ異なり、Δ := T'_1 − T_1、他は同一。
- 行ベクトル x₀ ∈ V*、列ベクトル y ∈ V を固定する。
- 語 w = (w_1,...,w_L) ∈ Σ^L に対し F(w) := x₀ T_{w_1} T_{w_2} ... T_{w_L} y、
  F'(w) は {T'_a} で同様に定める。

【定義】
D1. 左脱出指数 a := min{ |w| : x₀ T_w Δ ≠ 0 }（T_w は語 w に沿う合成、|w|=0 なら恒等）
D2. 右脱出指数 b := min{ |w| : Δ T_w y ≠ 0 }
D3. β := a + b + 1

【命題】
P1. 長さ L < β の全ての語 w について F(w) = F'(w) が厳密に成り立ち、
    かつ長さ L = β の語のうち少なくとも1つで F(w) ≠ F'(w) となる
    （後者は D1, D2 を達成する語の連接で実現される）。

【既に検討済みの還元先】
なし
```

**こちら側の期待:** 還元成功（部分実現理論／非可換有理級数／Krylov）。
その場合の写像が具体的に出てくることに価値がある。`docs/reduction-targets.md` G 節と照合する。

## シート2 — 【A1-2】間隙因子化則（主張B2）

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回

```
次の命題について、上記の手順で判定せよ。

【前提】
- シート1の【前提】と同一（Σ, V, {T_a}, {T'_a}, Δ, x₀, y）。
- さらに、左脱出指数 a、右脱出指数 b、β = a+b+1 が定まっているとする。
- rank Δ = r とする。

【定義】
D1. 長さ β の語のうち、文字 1 が位置 a+1 にただ一度だけ現れ、
    前置語 u（|u| = a）と後置語 v（|v| = b）を持つものを w(u,v) と書く。
D2. 間隙行列 G を G[u,v] := F'(w(u,v)) − F(w(u,v)) で定める
    （u は長さ a の語、v は長さ b の語を走る）。

【命題】
P2. G[u,v] = (x₀ T_u) Δ (T_v y) が厳密に成り立ち、
    行列 G の階数は rank G ≤ r = rank Δ を満たす。
    特に r = 1 のとき G[u,v] = α(u)·γ(v) と完全に分離する。

【既に検討済みの還元先】
なし
```

**こちら側の関心:** この rank 制約から held-out 語のギャップを盲予測できるか（predictive surplus）。
還元されても「既知の道具で予測できる」なら、予言の新規性のみが失われる。

## シート3 — 【A1-3】盲点集合の次元・安定性（stratum 主張）

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回
> **これは「微調整による相殺ではない」という主張の本体。** 監査が要求した
> cancellation-protected 例外集合の性質そのもの。

```
次の命題について、上記の手順で判定せよ。

【前提】
- シート1の【前提】と同一。
- 部分空間 W ⊂ V（dim W = k, 1 ≤ k < n）を固定する。
- Δ は「行支持が W に含まれ、かつ Δ y = 0」という条件を満たすものに限る
  （すなわち Δ ∈ 𝔇 := { Δ : im Δ* ⊆ W, Δ y = 0 }）。
- x₀ は W と交わらない：x₀|_W = 0、かつ x₀ T_w|_W = 0 が |w| ≤ a−1 で成立。

【定義】
D1. 盲点集合 B_L := { Δ ∈ 𝔇 : 長さ L 以下の全ての語 w で F(w) = F'(w) }

【命題】
P3. B_{β−1} は 𝔇 の中で正の余次元を持つ部分多様体ではなく、
    𝔇 全体（すなわち相対的に開かつ稠密な部分集合ではなく、線形部分空間そのもの）と一致する。
    言い換えると、盲点は Δ の係数の微調整によらず、
    支持条件（im Δ* ⊆ W かつ Δ y = 0）のみから従う。

【既に検討済みの還元先】
なし
```

**注意:** この命題は「一般の HMM は有限語長で同定可能」（generic identifiability）と
**両立する**。generic 集合の補集合に正次元の集合があるという主張であり、矛盾ではない。
赤チームが「Huang et al. 2016 と矛盾する」と判定した場合、その判定は誤りなので
根拠を求めて再検討させること（ただしこちらから先に指摘しない）。

## シート4 — 【A2-1】量子（GKSL）実現の存在

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回
> **最優先の1枚。** これが否定されると理論の物理層が空になる（§4 stop condition 2）。

```
次の命題について、上記の手順で判定せよ。

【前提】
- 有限次元ヒルベルト空間 H（dim H = d < ∞）、密度作用素の空間を 𝔅 とする。
- 時間局所な GKSL 生成子 L₀（自由発展）と、有限個の CPTP 写像の族
  {Φ_a}_{a∈Σ}（介入。各 Φ_a は完全正値・トレース保存）を考える。
- protocol とは、初期状態 ρ₀ に対し Φ_{w_1}, Φ_{w_2}, ..., Φ_{w_L} を
  固定時間間隔の自由発展 e^{τL₀} を挟んで順に作用させ、
  最後に固定 POVM {E_k} で測定する操作をいう。深さ = L。
- トランスクリプト分布とは、この操作で得られる測定結果の確率分布をいう。

【定義】
D1. 2つの介入族 {Φ_a}, {Φ'_a} が「深さ L で識別不能」であるとは、
    深さ L 以下の全ての protocol（文字列の任意の選び方、両順序を含む）について
    トランスクリプト分布が厳密に一致することをいう。
D2. 脱出深さ β := 識別不能でなくなる最小の深さ。

【命題】
P4. 任意の整数 β ≥ 3 に対し、次を満たす組が存在する：
    有限次元 H、GKSL 生成子 L₀、初期状態 ρ₀、POVM {E_k}、
    および1文字でのみ異なる2つの CPTP 介入族 {Φ_a}, {Φ'_a} であって、
    Φ_1 ≠ Φ'_1 かつ脱出深さがちょうど β となるもの。

【既に検討済みの還元先】
古典（可換）な場合には具体的な構成が存在することを数値的に確認済み。
量子（非可換・CPTP制約下）での存在は未確認。
```

**判定の読み方:**
- 「還元成功（= decoherence-free subspace / dark state の不可視性の言い換え）」→
  それでも**存在**は肯定されるので理論は生きる。ただし新規性の重心が §4.1 の (i)(iii) に移る。
- 「命題は偽（CPTPが禁止する）」→ **理論の物理層が空。撤回**（stop condition 2）。
- この2つは全く違う結果なので、**判定文で必ず区別させること**。

## シート5 — 【A2-2】実現可能性ギャップ（分類主張・本命）

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回
> **提案22の「新しい問い」の本体はこの1枚。** 最も重要。

```
次の命題について、上記の手順で判定せよ。

【前提】
- シート4の【前提】（量子・CPTP版）と、その可換な特殊化（古典版）の両方を考える。
  古典版とは、全ての作用素が固定基底で対角な確率行列に制限された場合をいう。
- 系の次元 d、脱出深さ β、および介入差の階数 r（量子版では
  Liouville 空間上の超作用素 Φ_1 − Φ'_1 の階数）を資源指標とする。

【定義】
D1. 実現可能集合 R_cl := { (d, β, r) : 古典版で実現する組が存在する }
D2. 実現可能集合 R_q  := { (d, β, r) : 量子（CPTP）版で実現する組が存在する }

【命題】
P5. R_cl ≠ R_q である。すなわち、完全正値性の制約は、
    古典確率過程では実現可能なある (d, β, r) の組を禁止する
    （または逆に、古典では不可能な組を量子でのみ可能にする）。

【既に検討済みの還元先】
なし
```

**判定の読み方:**
- 「命題は偽（R_cl = R_q）」→ 分類定理が退屈になる。中心を no-go とギャップ因子化則に縮小し、
  **PRL/PRA 型へ降格**（stop condition 3）。理論は死なないが PRX の物語は消える。
- 「還元成功」→ 既存の量子 vs 古典分離の枠組み（例：量子 memory コスト、PSD rank）に
  吸収される。§6.4 却下表へ。
- **この命題が「還元失敗×3」なら、提案22は L3 候補へ昇格する。**

## シート6 — 【A1-4】資源制限下界（主張B4）

> **送り先:** 還元プロジェクト（指示A）／ **反復:** 3回
> シート1・4・5 の判定が出てから回す（優先度は下）。

```
次の命題について、上記の手順で判定せよ。

【前提】
- シート4の【前提】（量子・CPTP版）。
- ただし完全な識別不能ではなく、初期状態が微小な漏れを持つ場合を考える：
  ρ₀(η) = (1−η)ρ₀ + η σ、σ は W 上に支持を持つ状態、0 < η ≪ 1。
- 観測者は深さ L < β の protocol のみを使用でき、各 protocol について
  有限回の測定（総ショット数 N）を行う。適応的な protocol 選択を許す。

【定義】
D1. 分離問題：2つの介入族のどちらが実装されているかを、
    誤り確率 α 以下で決定する仮説検定問題。

【命題】
P6. 深さ L < β に制限された任意の観測者（適応的設計を含む）について、
    誤り確率 α 以下で分離するために必要なショット数は
    N ≥ c(α) / (η² · ‖Δ‖²) を満たす。特に η = 0 では有限ショットでの分離は不可能である。

【既に検討済みの還元先】
なし
```

## シート7 — 【A1 文献照合】調査役プロジェクト用

> **送り先:** **文献調査プロジェクト（指示B）** — 還元プロジェクトとは別プロジェクト
> **反復:** 1回（ただし出てきた文献のDOI/arXiv番号は必ず実在確認する）

```
次の数学的対象について、先行研究・競合研究を洗い出せ。

有限集合 Σ 上の文字に対応する行列族 {T_a}（有限次元）、初期行ベクトル x₀、
読出し列ベクトル y から定まる語関数 F(w) = x₀ T_{w_1}...T_{w_L} y を考える。
1文字の行列を Δ だけ摂動したとき、

(1) 長さがある閾値 β 未満の全ての語で F が不変となる条件、
    および β を Δ の左右の「脱出指数」で与える公式
(2) 閾値ちょうどの長さでの差の因子化と、その階数が rank Δ で抑えられること
(3) 上記の摂動集合が、係数の微調整ではなく支持条件のみで特徴づけられること
(4) この種の摂動対を hard instance とする、区別問題のサンプル数下界
(5) 行列が完全正値写像（CPTP）である場合に (1)-(3) がどう制限されるか

について、既存の結果があるか。特に次の分野を確認せよ：
線形系の部分実現理論、非可換形式冪級数の有理実現、
隠れマルコフモデルの等価性判定と識別可能性、HMM学習のサンプル下界、
量子チャネル識別、特異統計モデル。
```

**重要:** (5) に既存結果があるかが最大の関心事。(1)-(4) は既知でも理論は縮小するだけだが、
(5) が既知なら提案22は死ぬ。
