## 2. 完全復元は余次元2（Y2）

`g := R − R_∞` は複素数値。実2次元 `(u,v) = (Γε, Γ⁻¹)` 平面で `g = 0` は**2本の実方程式**である。
1次の実 Jacobian は

```
J = ∂(Re g, Im g)/∂(u,v) = [ −Re κ   Re α ]
                            [ −Im κ   Im α ]
det J = Im(κ_lift · conj(α_leak))
```

実測（厳密）: `det J = −290681/1065800 ≠ 0`、`rank_ℝ J = 2`、
かつ `det J` と `Im(κ·conj α)` の残差は厳密に 0。

> **⇒ `Im(κ_lift·conj(α_leak)) ≠ 0` である限り、`R → R_∞` の完全復元は
> `(Γ,ε)` 平面で孤立点であり、曲線として存在しない。**
> 完全復元を曲線として主張することは、ガイド §4.2 **no-go 9**（universal codimension-one の禁止）
> 違反であり、§8 の既指摘弱点「codimension-one の普遍化」の再発である。
> **初版 §0 の boxed 命題はこの誤りを含んでいた。**

Y6 のランダム 40 例でも `Im(κ·conj α) ≠ 0` が **40/40**——完全復元の余次元2は generic である。

## 3. 汎関数を固定すれば余次元1（Y3・Y4）

実応答汎関数 `Φ` を先に固定すると、`Φ(g) = 0` は**1本の実方程式**になる。

```
Φ(g) = −u·Φ(κ_lift) + v·Φ(α_leak) + O(2)
grad = (−Φ(κ), Φ(α)),   rank_ℝ = 1  （両成分が同時に零でない限り）
Φ-稜線:  Γ²ε = Φ(α_leak)/Φ(κ_lift)
存在条件: sign(Φ(κ_lift)·Φ(α_leak)) = +1   ← **開条件**
```

実測（厳密）:

| Φ | `Φ(κ)` | `Φ(α)` | rank | 符号積 | 稜線位置 `Γ²ε` |
|---|---|---|---|---|---|
| **Re**（分散） | `875103/532900` | `3421/10658` | 1 | `+1` | `171050/875103 ≈ 0.19546` |
| **Im**（吸収） | `−234347/532900` | `427/5329` | 1 | `−1` | `−42700/234347 ≈ −0.18221`（非物理） |

**存在条件は開条件であり微調整ではない。** Y6 のランダム 40 例で
Im稜線の存在率 **3/5**、Re稜線の存在率 **2/5** —— いずれも 0 でも 1 でもない。

### 厳密零点証明書（Y4、Sturm 法・浮動小数点不使用）

`Re(N/D) = Re(N·D*)/|D|²`、`Im(N/D) = Im(N·D*)/|D|²`（`D*` は係数を共役した多項式）。
`|D|² > 0` なので零点は各分子の実根に一致する。

## 4. 稜線対の分裂（新しい観測量）

分散稜線と吸収稜線の位置は一般に異なる。分裂幅は閉形式を持つ。

```
Δ_split := Re(α)/Re(κ) − Im(α)/Im(κ)
         = [ Im(κ)Re(α) − Re(κ)Im(α) ] / [ Re(κ)·Im(κ) ]
         = Im(κ_lift · conj(α_leak)) / [ Re(κ_lift)·Im(κ_lift) ]
```

**分子は Y2 の `det J` そのものである。** したがって

> **分裂幅がゼロになる条件と、完全復元が可能になる余次元2条件は厳密に一致する。**

実測（厳密）: `Δ_split = 77451952450/205077762741 ≈ 0.37767`。
Y3 の2つの位置の差 `0.19546 − (−0.18221) = 0.37767` と一致する。

**物理的含意（EIT）:** 透過（吸収 `Im χ`）と位相シフト（分散 `Re χ`）は**別々に測る量**である。
本結果は「両者が**異なる `Γ·γ₁₂` で**理想 dark-state 値へ回復し、その差が閉形式で予言できる」
という予言に翻訳される。**単一の稜線より強い実験的 signature である**（2本の位置＋分裂幅の3つが予言される）。

## 6. ⚠️ Y7 — Step 3 の「CPTP 符号強制」先読みは成立しない

計画の Step 3 は次の先読みを置いていた。

> 自己応答 `p = c` では `(D_L)_PP ⪰ 0` から `κ_lift ≥ 0` が CPTP に強制され、
> 同様に `α_leak ≥ 0` も強制されて `sign(κ·α)=+1` が自動成立するのではないか。

**これは誤りである。**

```
κ_lift = c_P† B_PP⁻¹ (D_L)_PP B_PP⁻¹ c_P
```

は `B_PP⁻¹` が**2回**現れる**双線型形式**であり、sesquilinear 形式
（`c_P† B_PP^{-†} (D_L)_PP B_PP⁻¹ c_P` なら `⪰ 0` が従う）**ではない**。
`B_PP` が複素なら正値性は伝播しない。

実測（Y7、自己応答 `p=c` の 30 例）: **`κ_lift` が非実 30/30、`Re κ_lift < 0` が 16/30。**

> **⇒ CPTP による符号強制は `B_PP` が実（共鳴）の場合に限られる。**
> **Step 3 の no-go 経路（PRL 分岐）は当初の見込みより弱く、
> 「実現可能 → PRA」分岐の公算が高くなった。**
> ただしこれは線形代数レベルの反例であり、**GKSL 由来の `B_PP` が
> 追加の構造（Hermiticity・受動性）を持つ可能性は排除されていない**。
> Step 1–2 で GKSL から `B_PP` を実際に導出するまで、no-go 分岐を捨ててはならない。
