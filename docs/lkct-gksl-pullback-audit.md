> **次元二分律の `k ≥ 2` 側は、実在する5準位 GKSL 生成子で実現される。**

## 1. モデル（tripod 型5準位）

| 準位 | 役割 | 減衰 |
|---|---|---|
| `\|1⟩` | 参照状態 `ρ⁽⁰⁾ = \|1⟩⟨1\|` | — |
| `\|2⟩, \|3⟩` | **準安定 = 保護ブロック P** | Γ スケール減衰なし ⇒ `(D₀)_PP = 0`、**`k = 2`** |
| `\|4⟩, \|5⟩` | 励起 = 高速ブロック F | `L_j = √(Γd_j)\|1⟩⟨j\|` |

**厳密有理数パラメータ（凍結）**

```
低速減衰   γ₂ = 1/4 ,  γ₃ = 5/4              （Γ 非依存。保護コヒーレンスの残留減衰）
離調       Δ₂ = 1 ,  Δ₃ = −1 ,  Δ₄ = Δ₅ = 0
結合       J₂₃ = −1/4                        （P 内部、Raman/RF）
           J₂₄ = −1 , J₂₅ = −1 , J₃₄ = −2 , J₃₅ = 2   （P–F 光学結合）
高速減衰   d₄ = 7/4 ,  d₅ = 3/2
dephaser   L_φ = √(Γε)·diag(a₁..a₅),  a₁ = 1, a₂ = −4/3, a₃ = 2, a₄ = a₅ = 0
プローブ   Ω = 1/4（1↔2 を駆動）
読み出し   p = e₂（ρ₃₁ を読む）
```

**導出されたペンシル（完全 Liouvillian から抽出、手で置いたものではない）**

```
D₀   = diag(0, 0, 7/8, 3/4)
D_L  = diag(49/18, 1/2, 1/2, 1/2)
B_PP = [[1/8 + i,  −i/4 ], [ −i/4, 5/8 − i ]]
B_PF = i·[[−1, −1], [−2, 2]]       B_FP = i·B_PF/i のᵀ = i·J_PFᵀ
c_P  = (−i/8, 0)ᵀ                  p_P = (0, 1)ᵀ
```

**源と読み出しはともに P 支持**（`c_F = 0`）。前回監査 Z8 が示した
「標準 EIT のプローブ配置は保護支持クラスの外」という制約を、本モデルは正面から満たしている。
`p ≠ c̄` の交差転送であり、これは `k≥2` 機構（`row ≠ y†`）に必須である。

## 2. 新規に導出したもの — 凍結理論の空白を2つ埋めた

### 2.1 純位相緩和のコヒーレンスブロック寄与（V3）

EIT L.1115 は明示的に先送りしていた —
*"Pure dephasing must be derived separately from the adopted jump-operator normalization."*
SMRT には "dephas" が1件もない。**LKCT の中心にある持ち上げ作用素 `(D_L)_PP` は、
このリポジトリで一度も jump operator から導出されたことがなかった。**

> **［純位相緩和の縮約則］（Exact）**
> `L_φ = √γ_φ Σ_j a_j |j⟩⟨j|` はコヒーレンス `ρ_{j,ref}` を
> **`−½ γ_φ (a_j − a_ref)²`** で減衰させ、他のコヒーレンスと結合しない。

内訳（`j=3` で表示）:

| 項 | 寄与 |
|---|---|
| `L ρ L†`（再生） | `+γ_φ a_j a_ref` |
| `−½{L†L, ρ}`（反交換子） | `−½γ_φ(a_j² + a_ref²)` |
| **合計** | **`−½γ_φ(a_j − a_ref)²`** |

**⇒ 構造的帰結: `(D_L)` は対角に強制される。** 非対角にするには遷移 jump が要るが、
それは減衰であって持ち上げではない。実現可能性の掃引は既に対角 `D_L` で 19.7% を得ており、
この制約は結論を変えない。

実装は `dephasing_block()`。`scripts/tpr_thermo_audit.py:97` の `damping_block` は
`(a,b,rate)` の遷移 jump 専用で `out[a] += rate` という流出和の形をしており、
**対角 jump を表現できない**（dephaser を `(a,a,rate)` と書くと誤って流出に加算される）。

### 2.2 弱プローブ線形化そのもの（V4）

SMRT `prop:phase-n` の証明（L.518）は *"linearization gives exactly the displayed pencil"* と
**主張するだけ**で、`D = ½diag(d_j)` の `½` すら計算していない。一方 `rem:gksl-model`（L.176）は
「各モデルは jump operator を書き下して誘導線形応答生成子を**導出**せよ」と要求している。
本監査はその導出を供給し、**凍結の主張と一致することを確認した**。

| 凍結の主張 | 本監査の導出 | 一致 |
|---|---|---|
| `L_j = √(Γd_j)\|1⟩⟨j\|` ⇒ `D = ½diag(d_j)`（SMRT L.460-461） | `(D₀)_FF = diag(7/8, 3/4) = ½diag(7/4, 3/2)` | ✅ |
| `a = γ₁/2 + iΔ₁`（SMRT L.1045、prop:phase-h） | `B_jj = γ_j/2 + iΔ_j` | ✅ |
| `B_jk = iJ_jk`（SMRT L.463） | `B_PF = iJ_PF`、`B_FP = iJ_PFᵀ` | ✅ |

**補題 L1 が実モデルで確認された:** `(D₀)_PF = (D₀)_FP = 0` が自動的に成立し、
Riesz 射影が直交射影に一致する。前回監査では `D₀ ⪰ 0` からの帰結として証明したが、
実際の GKSL でもそのとおりになる。

## 3. 実験予言 — 2本の稜線と分裂

| 量 | 厳密値 | 数値 |
|---|---|---|
| `κ_lift` | `−3212560/363245481 − 20514304i/363245481` | — |
| `α_leak` | `−136145216/847572789 − 78455360i/847572789` | — |
| **分散稜線** `Γ²ε` | `25527228/1405495` | **18.162447** |
| **吸収稜線** `Γ²ε` | `3677595/2243752` | **1.639038** |
| **分裂幅** `Δ_split` | `7443989642133/450511745320` | **16.523409** |
| 稜線位置の比 | `2727465184736/246135304025` | **11.081 倍** |

`Γ` は光学コヒーレンス damping スケール、`ε·Γ` は保護コヒーレンスの dephasing。
**分散側と吸収側が 11 倍離れた `Γ·γ_deph` で理想値へ回復する**というのが本理論の実験予言である。

### 3.1 ⚠️ 漸近領域に入る `Γ` が枝ごとに桁で異なる（新たな実験上の制約）

全次数 Sturm 認証（V7、判定基準は実行前に凍結）:

| 枝 | 漸近領域の開始 `Γ` | 相対差の縮小率（`Γ` 10倍あたり） |
|---|---|---|
| 吸収（Im） | **≈ 2×10²** | 0.1024 → 0.1002（厳密に `O(Γ⁻¹)`） |
| 分散（Re） | **≈ 2×10³** | 0.0696 → 0.0973 |

分散稜線は位置が 11 倍高いため、`u = Γε` を小さく保つのにより大きな `Γ` を要する。
`Γ = 200` では分散側の根は窓内に存在しない。**両稜線を同一実験で観測するには
`Γ ≳ 2×10³`（無次元）が必要**であり、これは前回監査までに出ていなかった制約である。

**注（正直な記録）:** `ε > 0` には稜線根とは別の実根も存在する。これは応答の別の特徴であり、
2-jet 窓 `[ridge/2, 2·ridge]/Γ²` の外にある。上記の窓はそれを分離している。

## 4. 対照と負制御

### 4.1 低速減衰は分裂の必要条件（V6）

`γ₂ = γ₃ = 0` とすると（`prop:phase-n` の `B_jj = 0` に相当）:

```
κ_lift = −160i/2601 ,  α_leak = −496i/2023     （共に純虚）
Re(κ) = 0 ,  Im(κ·conj α) = 0                  ⇒ Δ_split が 0/0 に退化
```

`B_PP` が純虚になり、源の位相 `−i` が `κ` と `α` に共通にかかるだけなので両者が整列する。
**分散稜線と吸収稜線が縮退し、分裂が消える。**

⇒ **`prop:phase-n` の `B_jj = 0` をそのまま使ってはいけない。**
保護コヒーレンスの Γ 非依存の低速減衰は「あると良い」ではなく「無いと現象が退化する」。

### 4.2 負制御（V8）

| ID | 非物理化 | 結果 |
|---|---|---|
| **NC1** nonherm | `H ≠ H†` | V1 が FAIL（補題 L2 の前提が壊れる） |
| **NC2** gain | `L += 0.4·I` | トレース保存が破れ V1 が FAIL |
| **NC3** negweight | `γ₂ → −γ₂` | `√(負)` が虚数となり jump が非物理 |
| **NC4** nolift | dephaser を除去 | `κ_lift = 0` ⇒ 稜線座標が未定義 |
| **NC5** inverted | jump 向き反転 `\|j⟩⟨1\|` | `(D₀)_PP = diag(13/8, 13/8) ≠ 0` ⇒ 保護ブロックが消滅、V4 が FAIL |

**NC5 が特に有益:** 保護ブロックの存在が jump の**向き**に依存することを示す。
励起状態から基底へ落ちる（`|1⟩⟨j|`）配置でのみ準安定準位が保護される。

## 5. 本監査が行っていないこと（監査限界）

1. **`k ≥ 3` は未検査。** `k=2` の1モデルのみ。
2. **物質系パラメータへの当てはめは未実施。** NV / SnV / Eu:YSO 等への pullback、
   および稜線位置が実験的に到達可能な `Γ·γ_deph` に入るかの検討は行っていない。
   したがってガイド §1.2 の降格条件「experimental pullback ができず抽象 parameter のまま」は
   **まだ完全には解消されていない**（準位系までは具体化されたが、物質は未指定）。
3. **符号条件を満たすパラメータ領域の分類は未実施。** witness は1点のみ。
   前回監査の掃引（物理的 `B_PP` で Re 19.7%・Im 18.5%）が頻度の目安を与えるが、
   本モデル族での境界の閉形式は求めていない。
4. **外部文献照合は未実施。** 符号付き／実トロピカル幾何（提案24 §5.2 item 1ter）は
   依然 egress 待ち。**本監査の結論はこれで死ぬ可能性が残る。**
5. **A1（2小パラメータ特異摂動論への還元）は未決着。** 計算では決着しない。
   剰余は「CPTP クラス内の実現可能性分類」に置く。赤チーム Stage 2 の対象。
6. **A3（anti-Zeno）/ A4（ENAQT）の判別テストは未実施。**
