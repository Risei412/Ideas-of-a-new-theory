## 0. 結論 — 次元二分律

> **保護回復稜線の存在は、保護ブロックの次元 `k = dim P` によって二分される。**
>
> - **`k = 1`: 禁止。** Hermitian な `H` と完全正値性の下で、`α_leak = −(m/d_L)·κ_lift` が
>   厳密に成立する（比は負の実数で、`p_P, c_P, B_PP` とすべての離調に依存しない）。
>   したがって **Re/Im に限らず、あらゆる実線型汎関数 `Φ`** について
>   `Φ(κ_lift)Φ(α_leak) = −(m/d_L)Φ(κ_lift)² ≤ 0`。稜線座標 `Γ²ε = −m/d_L < 0` は物理域外。
> - **`k ≥ 2`: 実現可能。** 物理的な `B_PP = S + iT`（`S` 実対角 PSD、`T` 実対称）の下でも
>   `Φ=Re` で 19.7%、`Φ=Im` で 18.5%、両方で 5.3% の頻度。明示的な厳密有理数 witness を構成した。
> - **起源:** 実現可能性は、**2つの実 PSD 行列 `M = J D_F⁻¹ Jᵀ` と `(D_L)_PP` が非比例である**
>   ことに由来する。比例させると（`M = λ D_L`）符号条件は 0/2000 となり `k=1` の no-go に厳密に退化する。

**投稿先判定: PRA（分類定理＋設計則＋実験提案）。** 純粋な no-go（PRL）ではなく、
純粋な実現可能性（PRA 短報）でもなく、**no-go と実現可能性が次元で分かれる分類**である。
PRX は依然として不可（提案24 §1.1 Novelty ゲート不合格の判断は変わらない）。

**提案24 §6 stop condition 2 は発火しない。** 条件は「GKSL 物理クラスで実現不能なら no-go 定理として
論文化」であったが、実現可能な次元が存在するため no-go 分岐へは行かない。撤回条件
（「すべての汎関数で、物理・非物理を問わず稜線が一切現れない」）も発火しない。

## 1. 監査前に訂正された2つの誤り

本監査は、着手時点の作業仮説を2つとも**否定**した。どちらも記録する。

### 1.1 次数混同（Z3）

作業仮説は `C_leak = −β/A`（`A = γ₃₁ − iΔ_p`）とし、そこから `ψ = π − arg A`、
`cos ψ < 0`、そして**二光子離調 `δ₂` による「離調窓」**を予想していた。

**これは次数の混同であった。** 厳密な Schur 漏洩項

```
−v·B_PF (D_F + v·Ω_FF)⁻¹ B_FP
```

の `v¹` の係数は `−B_PF D_F⁻¹ B_FP` であり、`Ω_FF`（したがって `B_FF`・離調）は
**`v²` で初めて現れる**。`α_leak` は 2-jet の `v¹` 係数なので、`D_F⁻¹` のみを含む。
`(ΓD_F + B_FF)⁻¹` を使う読みは `O(v²)` の項を `O(v)` の係数に混ぜている。

**⇒ 「離調窓」という予想は棄却される。`ψ` に離調依存性は存在しない。**

### 1.2 補題 L2 — `ψ = π` が厳密（Z2）

`H = H†` より coherence ブロックの P–F 結合は `B_PF = iJ_PF`、`B_FP = iJ_FP = iJ_PFᵀ`
（`J` は実）。`D_F` は実正定値対角（Davies 型 jump）。したがって

```
C_leak = B_PF D_F⁻¹ B_FP = (i)(i)·J_PF D_F⁻¹ J_PFᵀ = −J_PF D_F⁻¹ J_PFᵀ =: −M
```

で **`M` は実対称 PSD**。`k=1,2,3 × n_f=1,2` の全ケースで厳密に確認した。
`arg(C_leak) = π` が厳密に成立し、離調に一切依存しない。

## 3. Λ/EIT 系は二重に排除される（Z8）

**これは提案24 の実験翻訳に対する訂正を要求する重要な発見である。**

凍結 EIT 文書 §9.2 の線形系は

```
[[A, iΩ_c d₂/2], [iΩ_c* d₂†/2, γ_g]] (x, s)ᵀ = (iΩ_p d₁/2, 0)ᵀ
```

- `x` = 光学コヒーレンス、damping `A = γ₃₁ − iΔ_p` が `Γ` スケール → **F ブロック**
- `s` = 基底コヒーレンス、`γ_g = γ₂₁ − iδ₂` は低速 → **P ブロック**

LKCT は `c = (c_P, 0)`、`p = (p_P, 0)` を要求する（提案24 L157–158）。ところが標準 EIT では

```
c_P = 0,  c_F = iΩ_p/2  ≠ 0        p_P = 0,  p_F = 1 ≠ 0
```

**源も読み出しも F ブロックに載っており、LKCT の支持条件と正反対である。**

さらに Λ 系は基底コヒーレンスが1本なので `k = 1` であり、T1 によっても排除される。

### 3.1 提案24 §3.3 の要訂正箇所

> 「EIT では透過（`Im χ`）と位相シフト（`Re χ`）が**異なる `Γ·γ₁₂` で回復する**」

この予言は **F 支持の観測量**について述べられており、そのままでは正当化されない。
`Δ_split` の閉形式自体（Step 0 監査で厳密に導出）は生きているが、
**それが現れる観測量は光学コヒーレンスではない。**

**P 支持の観測量にするには基底コヒーレンスを直接読む必要がある**
（Raman / RF / スピンコヒーレンス読み出し、二光子駆動源）。
そして `k ≥ 2` が必要なので、**単一の Λ 系では足りず、基底コヒーレンスが2本以上ある系**
（tripod、double-Λ、あるいは基底多様体に2本の独立コヒーレンスを持つ系）が要る。

## 4. 負制御（Z7）

`scripts/wpot_null_smoke.py` の分類（inverted / gain / negweight）に倣った。

| ID | 非物理化 | 結果 |
|---|---|---|

**Hermiticity が正確にその原因である**ことを示す。

## 5. 本監査が行っていないこと（監査限界）

正直に列挙する。

1. **完全 Liouvillian との突合を行っていない。** 本監査は応答ペンシル
   `Γ(D₀+εD_L)+B(z)` のブロック構造レベルで閉じている。`prop:phase-h` が行ったような
   `d²×d²` 完全 Liouvillian との数値照合（4.5e-16）は未実施。
   **したがって「この構造を持つ具体的な4準位 GKSL を書き下した」とは言えない。**
   `k≥2` の witness は**構造的に可能**であることを示すが、**具体的な準位系・jump リスト・
   レートへの pullback は次工程**である。
2. **`k ≥ 3` は未検査。** `k=2` のみ。
3. **非 Davies（path-coherent）jump は範囲外。** 低速な path-coherent jump は `B_PF` に実部を
   与えうるので CPTP 内で L2 を回避する経路になりうるが、本監査では列挙していない。
4. **A1（2小パラメータ特異摂動論への還元）は未決着。** これは計算では決着しない。
   本監査が与える剰余は「CPTP クラス内の実現可能性分類」であり、
   matched asymptotics はこれについて何も言わない、という論法に依存する。**赤チーム Stage 2 の対象。**
5. **A3（anti-Zeno）/ A4（ENAQT）の判別テストは未実施。**
6. **文献照合は一切行っていない**（ユーザ判断で今回の範囲外）。
   符号付き・実トロピカル幾何の監査（§5.2 item 1ter）も未実施のまま。

## 6. 次工程

1. **`k=2` の witness を具体的な GKSL へ pullback する**（最優先）。
   出発点は SMRT `prop:phase-n`（全データ有理数、5準位、`L_j = √(Γd_j)|1⟩⟨j|`）で、
   `d_j` を2つ 0 にすると `D = ½diag(0,0,d₄,d₅)` となり `k=2` が直接得られる。
   `(D_L)_PP` は明示的な dephasing jump から供給し、完全 Liouvillian と突合する。
2. `k ≥ 3` への一般化、および `k` に関する一般定理の可否。
3. path-coherent な低速 jump による L2 回避経路の列挙（`k=1` の no-go の抜け道の有無）。
4. A1/A3/A4 の判別テストと赤チーム Stage 1–2。
