## 0. 結論

反論は**半分正しく、正しい半分は致命的ではないが、理論の正体を変える**。

1. **Edge (i) は全面的に認める。** 定常bathから導出された生成子では $h$ は自動的に Herglotz であり、
   C2 は恒等的に成立する。**C2 違反は新しいダイナミクスの発見ではなく、宣言された
   architecture に対する反証である。**
2. **Edge (ii)（$S$ は $\gamma$ のHilbert変換ゆえ独立データではない）は透明窓が退ける。** ただし
   守るべき命題は「不決定性」ではなく**到達可能性**（命題 (N)）であり、そこが本体である。
3. **新たに $b$ 項の修理が必要**（§4）。$b\succeq0$ を自由にしたままだと **2点 witness は
   十分条件にもなってしまい、$n=2$ に補間論的内容が無い**。物理的bathの有限重みから
   $b=0$ を導けば抜け穴が閉じ、監査で格下げした C6 が復活する。
4. **最も鋭い反論は vacuousness ではなく検定力である**（§7）。閉形式で解くと、
   C2 が発火するには利得チャネルの重みが吸収重みを**上回る**必要があり、
   その領域では非受動性は既に露骨である。**検定力は大きいが限界情報がほぼゼロ。**
5. **最重要の未解決問題は Edge (iii)**（§5）——対称性の二重拘束。CG2 が要求する縮退を
   保護する対称性を bath も共有するなら quantum surplus は恒等的にゼロになる。
   逃げ道（異方的bath）が自己矛盾しないかは**誰も確認していない**。

生き残るスコープは §8 に確定形で記す。**物理ではなく計測機器としての価値**であり、
§11 の PRX 物語は撤回すべきである。

$$\boxed{\;S(\omega)=\mathrm{P.V.}\!\int\frac{d\omega'}{2\pi}\,\frac{\gamma(\omega')}{\omega-\omega'}\;}$$

## 2. Edge (i) — 全面的に認める

$C(s)=\int\frac{d\omega}{2\pi}e^{-i\omega s}\gamma(\omega)$、$\gamma\succeq0$（Bochner）より、
$\mathrm{Im}\,z>0$ で

$$\Gamma(z)=\int_0^\infty\!\!ds\,e^{izs}C(s)=-i\!\int\!\frac{d\omega}{2\pi}\frac{\gamma(\omega)}{\omega-z},
\qquad
\mathrm{Im}\,h(z)=\mathrm{Im}(z)\int\frac{d\omega}{2\pi}\frac{\gamma(\omega)}{|\omega-z|^2}\succeq0 .$$

**任意の定常bathに対し $h$ は自動的に行列Herglotzであり、スペクトル測度は $d\mu=\gamma\,d\omega/2\pi$。
したがって C2 は恒等的に成立し、bath由来のデータでは障害は原理的に発生しない。**

さらに強く言える。透明窓上では $\gamma=0$ ゆえ、そこで生成子は**ユニタリ**である。
**C2 違反はそもそも生成子についての主張ですらない。** 補間点で使うデータは準位シフトの分光であって
散逸ダイナミクスではない。正しい読み方は

> **C2 は「透明な多ポート媒質の分散データに対する整合性試験」である。**

C2 違反が意味するのは、宣言した architecture のどこかが偽だということであって、
新奇な物理現象の存在ではない。この点は Pass 3 監査が独立に到達した結論と一致する。

## 3. Edge (ii) — 退けるが、守るべき命題を差し替える

**鋭い版の反論:** §1 より $S$ は $\gamma$ の Hilbert 変換であり、多項式項を除いて完全に決まる。
ならば「$\gamma$ と $S$ を測って整合を見る」のは単なる Kramers–Kronig チェックであって、
補間問題は存在しない。

**透明窓による反論:** $W$ 上では $\gamma\equiv0$ である。したがって $S|_W$ を決めているのは
$W$ の**外**にあるスペクトル重み $\mu$ であり、窓内の測定はその $\mu$ を一切見ない。
$S|_W$ は窓内データから決まらない。よって

> 「$W$ 外に台を持つ PSD 行列測度 $\mu$ で、標本点の $S$ を再現するものは存在するか」

は退化していない行列境界 Nevanlinna–Pick 実行可能性問題であり、C2 はその必要条件である。

**ただし、不決定性それ自体は検定を有意味にしない。** 守るべき命題は次である。

> **命題 (N).** per-port スカラー KK を満たし、実験が測れる他のすべてと整合し、かつ
> 行列条件 $M\succeq0$ を破る $S|_W$ データの集合が、**空でなく、かつ物理的に到達可能**である。

CIRT §4.4 の $\begin{pmatrix}1&2\\2&1\end{pmatrix}$ は「抽象行列として空でない」ことしか示していない。
**到達可能性が本体**であり、それを扱うのが §5（構造的到達可能性）と §6–7（機構と検定力）である。

### 3.1 付随する3つの論点

- **(a) 多項式項 $a+bz$** — $a$ は差分商で消えるが $b$ は消えない。§4 の修理を要する。
- **(b) $W$ 上の実解析性** — 「標本点＋滑らかさで接続が決まってしまい実行可能性が退化するのでは」
  という懸念は**逆**である。解析接続の一意性は「Herglotz な接続が存在するか」を剛性の高い
  yes/no にする。実行可能性問題が退化するのは制約集合が全体のときであって、候補が一意のときではない。
  **一意性は検定を強くする。**
- **(c) 区間で測れば過剰決定** — 同じく検定力であって空虚性ではない。むしろ $n$ 点 Loewner 行列で
  C5 の $P_n$ 階層を登れる。

## 4. $b$ 項の修理 — $n=2$ には補間論的内容が無い（新規・要反映）

CG2 が記録した erratum（$b$ は非対角ブロックにも入る）には、まだ引き出されていない帰結がある。

$b\succeq0$ を自由に許すと、**任意の** $M\succeq0$ は $\mu=0,\ b=M$、すなわち $h(z)=a+bz$
（純リアクタンス）で実現できてしまう。したがって

> **2点 witness $M\succeq0$ は2点実行可能性の必要条件であるだけでなく十分条件でもある。**

ゆえに $n=2$ には Loewner 不等式そのもの以上の補間論的内容が存在しない。
CIRT §6.1 が「有限判定体系」と呼ぶものは、$n=2$ では不等式の言い換えに過ぎない。

**修理:** 物理的な bath は総スペクトル重みが有限（$\int\gamma\,d\omega<\infty$）であり、
$z\to i\infty$ で $\Gamma(z)\to0$、したがって

$$\boxed{\;b=0\;}$$

が**導かれる**。$b$ は自由パラメータではない。これにより

1. 上の抜け穴が閉じ、
2. Pass 3 監査が「$b$ が浮いている限り汚染されている」として格下げした
   **C6（$\mathrm{rank}\,L=$ 最小bathモード数）が復活する**。

**CIRT は $b$ を追加条件として扱うのをやめ、有限スペクトル重みからの帰結として $b=0$ を宣言すべきである。**
補間論的内容は $n\ge3$ で初めて現れる。

## 5. Edge (iii) — 対称性の二重拘束（**最重要の未解決問題**）

CG2 の T5 は、非対角 $S_{ij}$ が存在し**かつ測定可能**であるには
(i) ポート間の Bohr 周波数の一致、(ii) ポート演算子の一次独立、が同時に必要であり、
生き残る最小構造は**対称性で保護された縮退多重項**、許容つまみは各ポート定義固有空間上で
**スカラー**である、と確定した。ここを押すと次の問題が出る。

現実の系で厳密縮退を保証するのは対称性（量子化軸まわりの回転不変性、時間反転、点群）であり、
許容つまみもその対称性と可換であることを要求される。したがって許容される族全体が
**対称性共変**である。ここで **bath も同じ対称性を持つならば**、$\Gamma_{ij}(\omega)$ は
対称性適合基底（$\sigma^\pm$）で**すべての $\omega$ について対角**となり、
$[S(\omega_1),S(\omega_2)]=0$、$M$ も同じ基底で対角、ゆえに

$$M\succeq0\iff\text{per-port スカラー KK}$$

**quantum surplus は恒等的にゼロ。** これは CIRT §9.1 の停止条件
「物理的制約により行列条件が対角条件から自動的に従う」そのものである。

**逃げ道は「bath が系の対称性を破る」（異方的・複屈折的環境）ことだが、代償が大きい。**
quantum surplus を持つ配位は「系の縮退を保護している対称性を、環境が破る」ものに限られる。
そして次が**誰も確認していない核心**である。

> $S_{12}\neq0$ を生む異方性は、secular 近似が要求する縮退そのものを解いてしまわないか。
> 両者は逆向きに引く。同じ異方性が $\omega_+\neq\omega_-$ を splitting させれば、
> T5 の一致条件が再び $S_{12}$ を殺し、surplus は生成されるのと同じ速さで消える。

これが成立すれば **G4（測度ゼロ・fine-tuning）の再演**であり、CIRT §9.1 の第1停止条件に該当する。

**本作業では結論を出さない。未解決として記録する。**
次の作業として最優先で推奨する。`scripts/cirt_gauge_audit.py` の T5 Gram 行列機構をそのまま
再利用でき、安価である（縮退2重項に強度 $\eta$ の異方的bath結合を入れ、
Gram rank・縮退splitting・$\lVert S_{12}\rVert$ を $\eta$ の関数として出し、
surplus が splitting を生き延びるか、それとも $O(\eta)\cdot[\text{splitting}/\gamma]$ で
自己相殺するかを見る）。

## 6. どの機構が実際に C2 を破るか

C2 は次の4つから従う: (A) 上半平面解析性、(B) **スペクトル測度の正値性**、
(C) $\omega$ 非依存ポート基底、(D) 全 context 共通の $h$。
**必然的な違反を与えるのは (B) だけである。**

| 機構 | 判定 |
|---|---|
| 非定常・時間変調環境 | **破らない。** Floquet/サイドバンド平均は $S_{\rm eff}(\omega)=\sum_n\lvert c_n\rvert^2S(\omega+n\Omega)$、正重みによる Herglotz の凸結合ゆえ再び Herglotz。変調は窓を動かすが錐を保つ。**context drift・緩慢変調も同断** |
| **パラメトリック駆動リザーバ** | **破る（構造的）。** Bogoliubov 二光子チャネルが $[a,a^\dagger]=1$ と逆符号で寄与し、実効スペクトル測度に負重み分枝が生じる。(A) ではなく (B) の破れ |
| **利得媒質・反転分布** | **破る（最も明快）。** 反転帯で $\gamma_{\rm eff}(\omega)<0$ ＝符号付き測度。利得線から離れた異常分散が、そのまま負の $M$ 方向である |
| 初期系–bath 相関 | 非斉次項を生み写像は非CP。そもそも $h$ が定義されず、試験すべき正準な $S$ が無い。導出の無効化であって違反ではない |
| 隠れた系準位 | **破らない。** 実エネルギーの隠れ準位は $\Sigma_S$ に正留数の極を与え、Herglotz のまま。**C4／Krein–Langer が CIRT に不利に働く**——隠れ準位が bath 構造に化けられるのは、まさに錐の中に留まるからである。反転した隠れ準位だけが破るが、それは利得の場合に帰着する |
| context drift | (D) の違反。警報であって物理ではない |
| 強結合 | 厳密自己エネルギーは Herglotz のまま。弱結合抽出公式が偏るだけ。警報 |

> **必然的に C2 を破る唯一の機構は、負のスペクトル重み——反転・利得・パラメトリック増幅である。**

### 6.1 独立な裏書き（Liu 2026, Remark 10）

`arXiv:2604.17058`（通読済み、`docs/literature-audit-cirt-passive-realizability.md` §4.1）の
Remark 10 は、受動性条件が破れるのは (i) bath が非平衡（駆動・スクイーズド）で利得を与える場合、
(ii) 実効 Hamiltonian が非Hermite（**利得媒質・PT対称系**）、(iii) 非物理な増幅を含む
現象論的 ansatz、と明記する。**上表と完全に一致する独立な確証である。**

### 6.2 自己矛盾の解消、および理論の正体の変更

フォトニックバンドギャップ、stop-band フィルタ、Purcell 抑制帯、対称性起源の dark state / DFS 窓は、
いずれも**受動線形構造**であり、そのインピーダンスは構成上 positive-real である。
**そこでは検定は決して発火しない。** CG8 が挙げる Eu³⁺:Y₂SiO₅ 案は、現状の構想のままでは
**保証された null** である。

発火しうるのは「窓が、probe ポートに対して受動的でない駆動媒質によって作られる、
あるいはそれと共存する」場合に限られる（Raman ゲイン、EIA 配位、
stop-band 内に置いた Josephson パラメトリック素子など）。

**これは理論の正体を変える。** witness は「因果性のプローブ」ではない。

$$\boxed{\text{透明媒質中の隠れた利得を検出する多ポート検出器}}$$

である。正直であり検証可能でもあるが、これは Grivet-Talocia らの意味での
passivity enforcement 問題でもある（Pass 3 §3 T-N4）。

**さらに:** Liu の Remark 10 は「これらの regime への定理の拡張は **ongoing work**」と述べ、
§IX は companion analysis で「reconstruction artifact と **genuine gain physics** を分離する
THz プロトコル」を予告している。**CIRT がここで到達した正体は、Liu の宣言済み進行中作業と重なる。**
Liu はスカラーの force-fit 再構成、CIRT は行列/多ポートの補間判定という差はあるが、
**隙間は狭く、閉じつつある。**

## 7. 検定力の閉形式 — vacuousness より鋭い反論

$b=0$（§4）のとき、$t\notin W$ で分母が正であることから

$$M=\int\frac{d\mu(t)}{(t-\omega_1)(t-\omega_2)}$$

は $d\mu$ の**正重み平均**である。媒質をポートに整列した吸収2チャネル＋角度 $\theta$ の
利得1チャネルでモデル化すると

$$M=\mathrm{diag}(\alpha,\alpha')-\beta P_\theta,\qquad
P_\theta=\begin{pmatrix}c^2&cs\\cs&s^2\end{pmatrix},\quad c=\cos\theta,\ s=\sin\theta,
\quad \alpha,\alpha',\beta>0 .$$

- **per-port 古典 KK が成立**（対角 $\succeq0$）: $\beta\le\alpha/c^2$ かつ $\beta\le\alpha'/s^2$
- **行列違反**: $\det M=\alpha\alpha'-\beta(\alpha s^2+\alpha'c^2)<0$
  $\iff\ \beta>\dfrac{\alpha\alpha'}{\alpha s^2+\alpha'c^2}$

$\alpha=\alpha'=1,\ \theta=45^\circ$（$c^2=s^2=\tfrac12$）では、両立領域は

$$\boxed{\ \beta\in(1,\,2)\ }$$

$\beta=1.5$ で $M=\begin{pmatrix}0.25&-0.75\\-0.75&0.25\end{pmatrix}$、
$\mathrm{spec}(M)=\{-0.5,\,1.0\}$、相対マージン $-\lambda_{\min}/\lVert M\rVert=0.5$。

> **検証状態:** 上記は**手計算で検算済み**（$\det M$ の展開、固有値、マージン）。
> **数値検証は未実施**（ユーザーのスコープ選択により本作業では行わない）。

**読み方:**

- **良い報せ:** 発火時のマージンは大きく、微調整された細片ではない。測定誤差は問題にならない。
- **悪い報せ:** 条件は実質 $\beta>\alpha$、すなわち**利得チャネルのスペクトル重みが
  各ポートの吸収重みを上回る**ことである。そのとき媒質は総重みが負の露骨な非受動系——
  閾値下のレーザーであり、明白な利得線を持つ。実験者は既に知っている。

> **C2 witness は検定力は大きいが、限界情報がほぼゼロである。**
> 非受動性が既に露骨な領域でのみ発火し、利得が吸収への小摂動である限り沈黙する。

**これは vacuousness 反論より鋭い、本計画の実用価値に対する最大の反論であり、3行で従う。**
（数値モデルを回しても得られる追加情報はほとんど無い。回すべきは §5 の Edge (iii) である。）

## 8. 生き残るスコープ（確定形）

> CIRT は、複合仮説 {定常・受動・弱結合・secular・因子化初期状態・凍結ポート基底・
> context 横断で共通の環境} に対する有限・gauge 不変な反証試験であり、
> 窓内の減衰データと冗長でない分散データを用いる。教科書的 per-port Kramers–Kronig に対する
> 余剰は、ちょうど**多ポート（行列）受動性**である。

付すべき留保3点:

1. **「減衰データと冗長でない」が真なのは窓内だけであり、しかもそれは窓内に減衰データが
   無いからである。** 窓外では Edge (ii) が完勝する。**検定の定義域は、開放系的内容が
   ゼロの場所とちょうど一致する。**
2. **複合仮説を分解できない。** 発火は7つの連言のどれか1つが偽だと告げるだけで、
   うち6つは退屈である（drift、強結合、隠れ準位、初期相関、ポート基底誤り、secular 破綻）。
   面白い1つ（非受動性）に事前確率を集めるには、他の6つを独立に統制する必要がある。
   1ビットを得るための実験コストとしては重い。
3. **行列余剰は回路理論の教科書事項である**（Pass 3）。CIRT §4.4 の見出し「quantum surplus」は、
   §12 が自ら禁じた命名を本文で繰り返している。**改名すべきである。**

**価値の所在は物理ではなく計測機器である。** 多ポート量子デバイスの較正診断——
準位シフトデータのみから、process tomography を要さずに、隠れた利得・ポンプからの
パラメトリック漏れ・未モデル化の共有リザーバを検出する。PRApplied 水準の実在する寄与であり、
Pass 3 監査の判定と一致する。**§11 の PRX 物語は撤回すべきである。**
