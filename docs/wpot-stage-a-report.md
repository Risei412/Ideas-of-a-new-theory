## 3. 失敗の機構（記録すべき本体）

`R(w u(θ) w') = Σ_k c_k e^{θλ_k}` において、`λ_k ≤ 0` は詳細釣り合いGKSLから確かに従うが、
**係数 `c_k` の正値性はどこからも従わない。** `c_k = ⟨E, v_k⟩⟨w_k, ρ₀⟩` は
readout POVM `E` と初期状態 `ρ₀` の生成元への射影の**積**であり、両者は互いに独立に選べる。
浴の熱性は**生成元のスペクトル**（`λ_k`）を制約するが、**読出し・初期状態の幾何**（`c_k`）を制約しない。

> **一般化された教訓:** 周波数領域の Herglotz/Pick 構造は、応答が
> `h(z) = −V†(z−H)⁻¹V` という**両側を同じ `V` で挟んだ**レゾルベント形をとることに由来する。
> この「両側が同一」という構造が正値スペクトル測度を生む。
> **語領域では source（`ρ₀`）と readout（`E`）が独立**であり、挟み込みが対称でない。
> したがって受動性は**片側形の正値性としては語領域に降りてこない。**
> これは実装の不備ではなく、対象の構造的性質である。

この機構は WPOT 固有ではない。**source/readout を独立に選べる任意の応答理論**に対し、
「受動性 ⇒ 語領域データの正値性」型の主張が同じ理由で成立しないことを示唆する。

## 4. 撤回の範囲と残る資産

**撤回するもの:**
- WP1（語領域受動性条件）そのもの。**Conjecture ですらなく、反証済み。**
- 「次元自由排除（DFPE）」が語領域 Loewner 行列で認証できるという主張の全体。
- 提案23 の中心命題。**番号23は欠番として残す**（ガイド §9・§6.6）。

**残す資産:**
1. **§3 の機構的知見** — 「source/readout の独立性が片側正値性を壊す」。
   これは**次に受動性ベースの witness を設計する際の必要条件**を与える：
   `E` と `ρ₀` を独立に選ばせない（例：`E = ρ₀` に固定した自己相関型 functional、
   あるいは KMS 内積で共役に結んだ pair）構成でなければ、同じ理由で死ぬ。
2. **`scripts/wpot_null_smoke.py`** — 負制御を含む語領域 null-identity 検定器。
   受動群・対照群の4モードは他の witness 候補の検定力チェックに再利用できる。
3. **CIRT C4 スモークとの整合** — C4（周波数領域での ancilla 閉性）は依然として違反ゼロである。
   **矛盾ではない。** 死んだのは「周波数領域の受動性構造を語領域へ移す」写像であって、
   受動性そのものの閉性ではない。

**取り消さないもの（誤解防止）:**
`docs/p0d-derivability-audit.md` §7 の処方「補助系を足しても消えない障害を中心に置け」は
有効なままである。本 Stage A が示したのは、その処方の**特定の実装経路（語領域 Loewner）が
通らない**ことであって、処方自体の誤りではない。

## 5. 次にどこを叩くか

§3 の必要条件を満たす候補は、現時点で次の順に見える。

1. **自己共役 functional 上での受動性** — `E` と `ρ₀` を KMS 内積で結んだ
   `R(w) = ⟨ρ₀, ℳ_w ρ₀⟩_KMS` 型。両側挟み込みが復活するため §3 の死因が構造的に消える。
   ただし線形応答の枠を出るため、ガイド §4.3 最終項（非線形 functional は
   passivity ordering を別途証明せよ）に抵触しないかの確認が先。

   本 Stage A の死因（正値性の非継承）とは独立。現時点で P0-2 の生存候補は DIBT のみ。
3. 上のいずれも通らなければ、**P0-2 全体の縮小**（PRL型の狭い古典資源分離主張、
   `p0d-derivability-audit.md` §6 が「有効な資産」として認めた範囲）を検討する。
