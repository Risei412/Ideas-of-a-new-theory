## 2. C1 の昇格 — 2-jet は近似ではない

### 2.1 厳密 Schur 還元恒等式（X1、残差厳密 0）

`u := Γε`, `v := Γ^{-1}` と置くと `A = Γ(D₀+εD_L)+B` に対し `vA = D₀ + v(B+uD_L)` であり、
`p, c` が保護ブロック支持であることから**近似なしに**

```
R(Γ,ε) = p_P† S(u,v)^{-1} c_P
S(u,v) = B_PP + u(D_L)_PP − v·B_PF (D_F + v·Ω_FF)^{-1} B_FP ,   Ω = B + u D_L
```

これは完全記号（k=1, n_f=1、9個の自由記号）で残差 `0`、凍結有理インスタンス（k=2, n_f=2）
の ± 両方で残差 `0`。**恒等式であって展開ではない。**

### 2.2 2-jet は解析的 Taylor 展開（gate 付き Exact）

`B_PP` 可逆・`D_F` 可逆のとき `S(u,v)` は原点の多重円板で解析的、`S(0,0)=B_PP` も可逆。
したがって `R` は原点で解析的で、

```
∂R/∂u|₀ = −κ_lift = −p_P† B_PP^{-1}(D_L)_PP B_PP^{-1} c_P
∂R/∂v|₀ = +α_leak = +p_P† B_PP^{-1}(B_PF D_F^{-1} B_FP) B_PP^{-1} c_P
```

**剰余は多重円板のコンパクト部分集合上で一様に `O(|u|²+|v|²)`。**
`(D_L)_PF` は 1次には効かない（`∂S/∂u|₀ = (D_L)_PP` に現れない）。

記号確認（k=1）: `R_∞ = c₁p₁/b₁₁`、`κ = c₁l₁₁p₁/b₁₁²`、`α = b₁₂b₂₁c₁p₁/(d_F b₁₁²)`、
閉形式との残差はいずれも厳密に 0。方向微分は4方向すべてで厳密有理数が一致（X2）。

> **⇒ C1 の status を Conditional から Exact（gate: `B_PP` 可逆・`D_F` 可逆・多重円板内）へ昇格。**

## 3. C2 の昇格 — 稜線は厳密な解析曲線

### 3.1 陰関数定理による存在証明

`g(u,v) := R − R_∞` は原点で解析的、`g(0,0)=0`、`∇g(0,0) = (−κ_lift, α_leak) ≠ 0`
（gate: `κ_lift ≠ 0` かつ `α_leak ≠ 0`）。よって零集合は原点を通る**解析曲線**であり、
接線は `−κ_lift·u + α_leak·v = 0`、すなわち `u = (α_leak/κ_lift)·v`。

物理域は `Γ>0, ε>0 ⇔ u>0, v>0`（開第一象限）。接線がここに入るのは
`α_leak/κ_lift > 0`、すなわち **`sign(κ_lift·α_leak) = +1` のとき、かつそのときに限る。**
`u=Γε, v=1/Γ` を戻すと `Γ²ε → α_leak/κ_lift`。

> **⇒ C2 の status を Conditional から Exact（gate 付き局所定理）へ昇格。**
> 稜線は「leading order の相殺」ではなく**厳密な零曲線**であり、
> 2-jet 公式はその接線（1次近似）である。

### 3.2 厳密数値証明書（X5、Sturm 法・浮動小数点不使用）

固定 Γ で `R−R_∞` の分子・分母を ε の多項式とし、実根を Sturm 列で厳密計数した。

| Γ | ridge 側：錐内ブラケット `[ε_pred/2, 2ε_pred]` の根 | 符号 | 2-jet 予測との相対差 |
|---|---|---|---|
| 500 | **1**（分母の根 0） | `+ → −` | `−2.67×10⁻³` |
| 5,000 | **1**（分母の根 0） | `+ → −` | `−2.68×10⁻⁴` |
| 50,000 | **1**（分母の根 0） | `+ → −` | `−2.68×10⁻⁵` |

相対差は **1 decade あたり厳密に 10 分の 1** に縮む。予測された `O(Γ^{-1})` 補正と整合。

no-ridge 側は **Γ = 500 / 5,000 / 50,000 のすべてで `ε>0` 全域の実根が 0 個**
（ブラケット内ではなく大域の証明書）。

> **注（正直な限定）:** ridge 側は `ε>0` 全域では根が **2 個**ある。第2根は `ε ≈ 0.1996`、
> すなわち `u = Γε ≈ 100` であり、**二重スケーリング錐の外側**にある遠方根で稜線ではない
> （2-jet の適用域外）。錐内の一意性のみを主張する。

## 4. C3 — fan 盲目性は確認、ただし主張の縮小が必要

### 4.1 凍結された fan-identical 対（すべて厳密有理数）

```
B_PP=[[2,1],[1,3]]  B_PF=I  B_FP=[[1,1],[0,1]]  B_FF=I  D_F=diag(1,2)
p_P=(1,0)  c_P=(0,1)  delta=1/100  (D_L)_FF=I
x = B_PP^-T p_P = (3/5, −1/5)     y = B_PP^-1 c_P = (−1/5, 2/5)

ridge   : w=(3, 4)   (D_L)_PP = ww^T + delta·I     kappa_lift = +499/500
no-ridge: w=(1, −2)  (D_L)_PP = ww^T + delta·I     kappa_lift = −501/500
両者共通 : alpha_leak = 2/25    R_inf = −1/5
```

`α_leak` は `D_L` に依存しないため **構成上厳密に共通**。両者とも `(D_L)_PP` は PD、
`D_L` 全体は PSD、`D₀` は PSD（X0 で Sylvester / 全主小行列式により厳密確認）。

### 4.2 トロピカル化は完全に一致する（X3）

`R − R_∞ = N(Γ,ε)/D(Γ,ε)` を厳密展開し、単項式の指数台を比較した。

```
num 指数台（11点）: (0,0),(1,0),(1,1),(2,1),(2,2),(3,1),(3,2),(3,3),(4,2),(4,3),(4,4)
den 指数台（12点）: (0,0),(1,0),(1,1),(2,0),(2,1),(2,2),(3,1),(3,2),(3,3),(4,2),(4,3),(4,4)
```

**± 対で num・den とも完全一致**（Newton 多面体も当然一致）。

経路 `ε = e₀Γ^{−θ}`（`e₀=1`）上の valuation `ν(θ) = −(Γ の leading 指数)` を
有理 θ 格子で厳密計算（`Γ=τ^q, ε=e₀τ^{−p}` による Laurent 化）：

| θ | 0 | 1/2 | 1 | 3/2 | 9/5 | 2 | 11/5 | 3 | 4 |
|---|---|---|---|---|---|---|---|---|---|
| ridge | 0 | 0 | 0 | 1/2 | 4/5 | 1 | 1 | 1 | 1 |
| no-ridge | 0 | 0 | 0 | 1/2 | 4/5 | 1 | 1 | 1 | 1 |

**± 対で完全一致。**

> **【提案24 本文の訂正】fan の折れ点は 1 個ではなく 2 個である。**
> 厳密形は `ν(θ) = clamp(θ−1, 0, 1)`、折れ点は **θ=1 と θ=2**。
> `θ ≤ 1` では `u = Γε` が発散して 2-jet の適用域外に出る（no-go 7 側の領域、
> `R→0` ゆえ `R−R_∞ → −R_∞ ≠ 0`、`ν=0`）。稜線が乗るのは **θ=2 の折れ点**のみ。
> 提案24 §2.2 は暗黙に折れ点1個を仮定していた。監査で発見・訂正した。

### 4.3 差が現れる唯一の場所 — 角 θ=2 の initial form（X4）

| | initial form（`Γ^{-1}` の係数） | 根 `e₀` | 物理域 `e₀>0` |
|---|---|---|---|
| ridge | `2/25 − (499/500)e₀` | `40/499` | **あり** |
| no-ridge | `2/25 + (501/500)e₀` | `−40/501` | なし |

いずれも予測 `−e₀κ_lift + α_leak` と**厳密に一致**（残差 0）。
`sign(κ_lift·α_leak)` による予測と実際の正根存在も 2/2 で一致。

### 4.4 ⚠️ stop condition 1 の評価（本監査の最重要成果）

提案24 §6 stop condition 1:
> 「A2 で稜線が**係数付き tropical 不変量**から決定できると判明 → §6.4 却下表へ」

**文字通りの読みでは発火している。** 角 θ=2 の initial form は標準的な係数付きトロピカル対象
（initial degeneration / Gröbner 退化）であり、稜線の有無はその根 `e₀ = α_leak/κ_lift` の
**符号**で完全に決まる。しかも符号情報を保持するトロピカル化は既存の枠組みである
—— **符号付きトロピカル化 / 実トロピカル幾何（Viro の patchworking、hyperfield 上の
トロピカル幾何、real tropicalization）** が正面から扱う対象である。

したがって現時点で言えるのは次の狭い命題だけである。

> **生き残っている命題（狭い版）:** 稜線は**非署名のトロピカル化**
> （Newton 多面体・valuation 関数 ν(θ) —— 計画18 の Newton fan と SMRT の polyhedral
> valuation が実際に計算している対象）に対して**不可視**である。
> 稜線を決定するには角の initial form の根の**実符号**が必要であり、
> これは実半代数的条件である。

**この狭い版は、それ自体としては新規性が弱い。** 上記の実トロピカル幾何の文献に
先行研究がある公算が高く、egress 制限下の本環境では文献確認ができていない。
