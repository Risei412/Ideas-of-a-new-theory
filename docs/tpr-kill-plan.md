### F2. T1(a) は `ass:singular` を読み違えている

提案 L.164–166 は

> `ass:singular` の「半単純・非自明核」仮定は (E1)–(E2) の下で満たせない
> （核1次元 ⇒ 保護Riesz射影は定常状態への rank-1 射影 ⇒ R_{S,0} の full/cut 差が消える）

と書く。しかし凍結された `ass:singular`（L.841）の原文は:

> For each $j\in\{\full,\cut\}$, **either $0\notin\spec D_j$, in which case set $P_j=0$ and $Q_j=I$**, or the eigenvalue $0$ of $D_j$ is semisimple and …
> If $P_j=0$, the corresponding protected contribution is defined to be zero.

すなわち `ass:singular` は**核なしの場合を明示的に許容する仮定**であり、
プリミティブな有限温度 Davies 生成子はこれを**満たす**。破らない。

さらに提案の括弧内の理由づけも誤っている。`ass:singular` の `D_j` は
全 Liouvillian ではなく**応答関連ブロック上の減衰作用素**であり、その核と
定常状態の縮退度は別物である。「核1次元 ⇒ rank-1 射影 ⇒ 差が消える」という推論は、
`eq:R0` が

$$\R_{S,0}(z)= p_{\full}^\dagger P_{\full}B_{P,\full}(z)^{-1}P_{\full}c_{\full} - p_{\cut}^{(S)\dagger} P_{\cut}B_{P,\cut}(z)^{-1}P_{\cut}c_{\cut}^{(S)}$$

と **`P_full` と `P_cut` を別々に持つ**ため成立しない。両者が rank-1 でも、
一般には異なるスカラーの差であって 0 にはならない。

**T1 は `ass:singular` を破る定理ではない。** 証明経路を書き直さない限り T1 は証明できない。

## 3. 判定基準の事前凍結

リポジトリ規約（`wpot_null_smoke.py`・`lkct_codim_audit.py`）に従い、
**判定に浮動小数点を使わない**（SymPy 有理数／Gauss 有理数 `ℚ(i)`、Sturm 法による厳密根計数）。
各ゲートについて、実行前にスクリプト冒頭へ次の3つを書く。

- **PASS 条件** — 何が示せたら通過か
- **FAIL 条件** — 何が出たら死か（提案文書 §6 の Stop 条件へ写す）
- **VACUOUS 条件** — 対照群が期待どおり壊れなければ検定力なしとして**判定を保留する**

負制御は `wpot_null_smoke.py` の4モード（passive / inverted / gain / negweight）を踏襲し、
TPR 固有のものとして次の3種を追加する。
