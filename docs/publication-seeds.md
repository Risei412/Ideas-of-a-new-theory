### S8. 操作的 Newton fan `ν(s) = a + z·s`

`‖R‖_p ~ h·w^{1/p}` からの導出は初等的で明快、`a`=高さ指数・`z`=幅指数という解釈も自然。
2つの独立認証済みスケーリング則が1つのアフィン式の特殊値として整列する点は説得力がある。

**ただし初版の中心命題 ACC（異常次数 = 実現余次元）は反例により撤回済み。**
中心は N3（face 係数写像の正則値定理）と N2（interface 非同定可能性）へ移されている。
**未監査。** LKCT の C3 が「符号付きトロピカル幾何に落ちる」で死んだ前例があり、
同じ層に落ちるリスクを共有する。

### S9. RRT 分岐指数

「非半単純保護核 ⇒ valuation が `(1/ℓ)ℤ` に乗る」。**脅威が明確に特定されている**
（例外点 EP／Lidskii 摂動論）。Jordan block からの Puiseux 指数はまさに Lidskii 理論そのものなので、
素朴な形では死ぬ。生き残るとすれば「**ramification index が振幅・Hankel rank・累積量のいずれにも
現れない独立な操作的不変量である**」という部分に限られる。

**kill test が短距離で実行可能**と自己判定されている。**安いので先に殺すべき候補。**
