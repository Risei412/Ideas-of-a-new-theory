## 3. Stage 1 で発見した内部不整合 → **2026-07-26 解消済み**

主張の抽出過程で、提案21および `p0-certificate-spec.md` の間に2件の食い違いを確認した。
**いずれも 2026-07-26 に解消し、提案21と spec §4quater を更新した。** 以下は経緯の記録である。

> **解消の要旨:** 認証対象を「43×43 の `σ₇`」から「**行・列語がすべて長さ2の 8×8 部分行列 `H_wit` の `σ₇`**」へ差し替え、
> calibration の protocol 集合を「長さ2以下の全語＝43 protocol」へ引き直した。
> 深さ4語は 64 個ちょうどで凍結 held-out 予算に一致し、予算変更は不要。
> `scripts/minor7_smoke.py` で `σ₇(H_wit) = 0.1934`（要求 `2τ_H(8) = 0.1265`、余裕 1.53×）を確認。

### 3.1 43×43 Hankel は凍結 shot 予算で測定できない

- `σ₇(H_full)` の判定には 43×43 の**全成分**が要る。成分は長さ4以下の語の値であり、
  相異なる語は `1 + 6 + 36 + 216 + 1296 = 1555` 個、うち深さ4が **1296** 語。
- 一方 spec §4.2/§4.5 の凍結予算は深さ4を **64 protocol** に限定している（128,000 shots）。
- 深さ4の全語を 2000 shots/setting で測ると **2,592,000 shots**。凍結値の **20.25倍**。

つまり `σ₇ ≥ 2τ_H` という判定条件は、現在の凍結予算では**実行できない**。
spec §1 の警告（「単にデータ点を表形式で切り分けるだけでは Hankel 部分行列にならない」）の具体的な現れである。

**検討した解と判定:**

| 案 | 内容 | 必要な深さ4語数 | 閾値 |
|---|---|---|---|
| **(a) 採用** | 判定を 43×43 の `σ₇` ではなく、**選んだ `k×k` 部分行列の `σ₇`** に置く | `k²` | `k=7`: 0.1183 ／ **`k=8`: 0.1265**（2000 shots） |
| (b) | 深さ4の予算を約20倍に拡張する | 1296 | `0.2933` |
| (c) | m を下げて語数を減らす | — | 要再計算 |

**採用は (a)、ただし `k=7` ではなく `k=8`。** 実測（`scripts/minor7_smoke.py`、seed 20260726）：

- **交錯の損失の方が閾値低下より大きい。** 同一構成点で `σ₇(H_full) = 0.66–0.75` に対し
  `σ₇(H_wit)` は 0.16–0.19。閾値は 2.48倍しか下がらないので、**部分行列版は構成側に不利**。
  ランダム構成の合格率は 0%（43×43 版は 6.8%）。
- **それでも最適化すれば通る。** 射影付き山登り1500反復で `k=7`: 0.1606（閾値 0.1183、1.36×）、
  `k=8`: **0.1934**（閾値 0.1265、**1.53×**）。反復に対し単調改善が続いており到達値は下界。
- **`k=8` を採る決め手は予算の一致。** 深さ4語が `8² = 64` 個ちょうどで、凍結 held-out 予算
  （深さ4を64 protocol）と過不足なく一致する。`k=9` 以降は 81 語で予算超過。
- 副次的な利点として、認証対象が exact minor 認証（提案 §5 ステップB）の対象と一致し、
  さらに主張4の成分間相関の問題も消える（8×8 の64成分は相異なる64語に一対一対応する）。

### 3.2 凍結された protocol 設計が Hankel の語構造と一致しない

- spec §4.1 の calibration 46 protocol の内訳は 深さ1: 6、深さ2: 16、深さ3: 24。
- 一方 `H_U`（7×7）が要求するのは**長さ2以下の全語**＝ 43語（深さ2は 36語すべて）で、深さ3は使わない。
- したがって凍結 protocol 集合は prefix–suffix 閉包をなしておらず、
  calibration 側で 16/36 の深さ2語しか測らない一方、Hankel が使わない深さ3語に 24 protocol を割いている。

**解消:** calibration の protocol 集合を **「長さ2以下の全語」＝43 protocol** と定義し直した
（深さ3の24 protocol は calibration から外れる）。これで prefix–suffix 閉包が成立し、
入れ子条件 (i) の「calibration データ」が43語の値として一意に確定する。
コストは 43 × 2000 = 86,000 shots（上限 1.2×10⁵）、2 settings なら 1395 shots/setting で 120,000。
**旧設計（46 protocol、うち深さ3が24）より安く、settings ≤ 2 も維持される。**

**確定した予算（m=6）:** calibration 43 + held-out 64 = **107 protocol、214,000 shots**（1 setting）。
