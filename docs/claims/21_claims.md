```

【前提】
- 有限アルファベット A = {1,…,6}。要素は操作ラベルとする。
- 語 w = u_1 u_2 … u_k（u_i ∈ A、k ≥ 0、空語を含む）。連接を u·v と書く。
- 実数値の応答 f : {語} → R が与えられている。すべての語で |f(w)| ≤ 1。
- 語集合 U = {w : |w| ≤ 1}（7語）、W = {w : |w| ≤ 2}（43語）。

  H_U は 7×7 で長さ2以下の語の値のみを使う。
  H_W は 43×43 で長さ4以下の語の値のみを使う。

【定義】
D1. 次数 r の線形実現とは、r×r 実行列の族 {V_u}_{u∈A} と
    ベクトル c, p ∈ R^r の組であって、
    f(u_1…u_k) = p^T V_{u_k} … V_{u_1} c
    がすべての語で成り立つものをいう。作用素ノルムは ‖V_u‖_2 ≤ 1 とする。

D2. 状態数 s の非負モデルとは、非負行列 T_u ∈ R_{≥0}^{s×s}（u ∈ A）と
    非負ベクトル b ∈ R_{≥0}^s の組であって、
    g(u_1…u_k) = 1^T T_{u_k} … T_{u_1} b
    と定めるものをいう。1 は全成分1のベクトル。
    正規化は各 T_u が列和 ≤ 1（substochastic）とする。

D3. 応答 f が「短語適合性 s をもつ」とは、状態数 s の非負モデルが存在して
    g(w) = f(w) が |w| ≤ 2 のすべての語で厳密に成り立つことをいう。

【命題】
P1. 次を同時に満たす応答 f が存在する。
    (a) f は次数 7 の線形実現をもつ。
    (b) f は短語適合性 6 をもつ（D3）。
    (c) rank H_W ≥ 7。

【既に検討済みの還元先】
なし
```

## 3. Stage 1 で発見した内部不整合（Stage 4 へ回す）

主張の抽出過程で、提案21および `p0-certificate-spec.md` の間に2件の未解決の食い違いを確認した。
**いずれも赤チームへ出す前に決着させるべき項目**である（不整合のまま還元試行に出すと判定が無効になる）。

### 3.1 43×43 Hankel は凍結 shot 予算で測定できない

- `σ₇(H_full)` の判定には 43×43 の**全成分**が要る。成分は長さ4以下の語の値であり、
  相異なる語は `1 + 6 + 36 + 216 + 1296 = 1555` 個、うち深さ4が **1296** 語。
- 一方 spec §4.2/§4.5 の凍結予算は深さ4を **64 protocol** に限定している（128,000 shots）。
- 深さ4の全語を 2000 shots/setting で測ると **2,592,000 shots**。凍結値の **20.25倍**。

つまり `σ₇ ≥ 2τ_H` という判定条件は、現在の凍結予算では**実行できない**。
spec §1 の警告（「単にデータ点を表形式で切り分けるだけでは Hankel 部分行列にならない」）の具体的な現れである。

**考えられる解（Stage 4 で判定）:**

| 案 | 内容 | 必要な深さ4語数 | 閾値 |
|---|---|---|---|
| (a) | 判定を 43×43 の `σ₇` ではなく、**選んだ 7×7 部分行列の最小特異値**に置く | ≤ 49 | `2τ_H = 0.1183`（2000 shots）／`0.1465`（1304 shots） |
| (b) | 深さ4の予算を約20倍に拡張する | 1296 | `0.2933` |
| (c) | m を下げて語数を減らす | — | 要再計算 |

**(a) が有力だが、無償ではない。** 部分行列の特異値は交錯不等式により
`σ_min(7×7部分行列) ≤ σ₇(H_full)` となるため、要求は**行列としては厳しくなる**（構成側の負担が増す）。
一方で閾値は `2τ_H` が 0.2933 → 0.1183 へ下がる（行列が小さいほどノイズの作用素ノルムが小さい）。
どちらが勝つかは未計算であり、**ステップ2のスモークを 7×7 部分行列版で再実行する必要がある**。
なお (a) は認証対象と exact minor 認証（提案 §5 ステップB）の対象を一致させるため、証明書としてはむしろ素直になる。

### 3.2 凍結された protocol 設計が Hankel の語構造と一致しない

- spec §4.1 の calibration 46 protocol の内訳は 深さ1: 6、深さ2: 16、深さ3: 24。
- 一方 `H_U`（7×7）が要求するのは**長さ2以下の全語**＝ 43語（深さ2は 36語すべて）で、深さ3は使わない。
- したがって凍結 protocol 集合は prefix–suffix 閉包をなしておらず、
  calibration 側で 16/36 の深さ2語しか測らない一方、Hankel が使わない深さ3語に 24 protocol を割いている。

**この不一致を解消しない限り、「calibration データを厳密に再現する非負モデル」の
「calibration データ」が何を指すのかが確定しない**（提案の D1／入れ子条件 (i) の定義が曖昧になる）。
予算表を Hankel の語構造に合わせて引き直すか、Hankel の添字集合を凍結 protocol 集合に合わせるかの選択。
