## 1. 最小模型

4準位（`g1, e1, g2, e2`）、すべて厳密有理数レート。probe は `g1↔e1` にのみ coherent に効く。

```
H = Δ|e1><e1| + (Ω_p/2)( e^{iθ}|e1><g1| + h.c. )

base jump（切らない）              ρ_{e1g1} の減衰への寄与
  √γ1 |g1><e1|   e1→g1              γ1/2
  √t  |g2><e1|   e1→g2              t/2
  √w  |e1><g1|   g1→e1              w/2
  √r  |g1><g2|   g2→g1              0   （L†L = r|g2><g2|）
  √u  |e1><e2|   e2→e1              0   （L†L = u|e2><e2|）
sector S jump（cut = 除去）
  √a |e2><g2|    g2→e2              0   （L†L = a|g2><g2|）
  √b |g2><e2|    e2→g2              0   （L†L = b|e2><e2|）
```

**設計の要:** `S` の台は `{g2,e2}` に直交射影で閉じており、probe optical coherence の
減衰係数 `Γ_coh = (γ1+t+w)/2` を**一切変えない**（F8 で極の位置として厳密に確認）。
したがって cut は `χ(Δ)` の Δ 依存性の形を変えず、`δχ_S(Δ) ≡ 0` は
「probe 遷移の population 差 `D_A = P_g1 − P_e1` が cut で不変」という
**1本の有理条件**に落ちる。この条件を `r` について厳密に解いて witness を構成した。

cut は jump operator の除去なので GKSL 形式を保つ（ガイド §4.2 no-go 1）。
初期状態・probe・readout・観測窓・正規化はすべて固定（同 no-go 2）。

**得られた witness（厳密有理数）:** `γ1=5, t=6, w=4, r=6/19, u=6, a=5, b=4`

| 量 | full | cut |
|---|---|---|
| `P_g1` | `3/11` | `11/91` |
| `P_e1` | `28/143` | `4/91` |
| `P_g2` | `152/429` | `76/91` |
| `P_e2` | `76/429` | `0` |
| **`D_A = P_g1−P_e1`** | **`1/13`** | **`1/13`**（不変） |
| **`Σ_A = P_g1+P_e1`** | **`67/143`** | **`15/91`**（δ = `304/1001`） |

## 3. ⚠️ F5：中心命題の書き方が空である

厳密な閉形式が得られた（残差 0）:

```
F_Q = 4|χ|² / Σ_A ,      χ = D_A · g(Δ)
```

すなわち **`δχ_S ≡ 0` は `D_A`（population 差）の不変性に、`δF_S ≠ 0` は
`Σ_A`（population 和）の変化に、それぞれ完全に帰着する。**

**問題は `Σ_A` が線形汎関数だということである。**

```
Σ_A = tr(ρ Π_A),   Π_A = |g1><g1| + |e1><e1|
```

sector は「ある線形汎関数には見えている」。したがって提案25 §0 の条件 (i)
（probe susceptibility だけの exact zero）は「非線形汎関数でしか見えない」という
主張を支えない。

**より一般に:** 有限次元でトモグラフィが可能な設定では、状態の任意の汎関数は
線形汎関数の全体から決まる。**「線形汎関数に盲目・非線形汎関数に可視」という
枠組みそのものが原理的に空である。**「非線形汎関数階層」を非自明にするには
資源制限（＝提案21/23 が占有する P0-2 の領域）か、以下の valuation 順序しかない。

→ 提案25 §6 の **stop condition 2 が発火**。

## 4. ⚠️ F7：分類予想の反証

§0 の分類予想は「`r_nc = rank[L_SLD, P_S] > 0` が `δF_S ≠ 0` の必要条件」であった。

本模型では **`r_nc = 0`（`L_SLD` の台は probe coherence のみで sector 射影と可換）
かつ `δF_S ≠ 0`**。**明示的反例であり、予想は偽である。**
`δF_S` を決めているのは非可換性ではなく `Σ_A` の変化のみだった。

## 5. ✅ 生き残った結果（F8）

閉形式と population の正値性から、**この模型を超えて**次が厳密に従う。

`P_g1, P_e1 ≥ 0` より `|D_A| = |P_g1 − P_e1| ≤ P_g1 + P_e1 = Σ_A` が恒等的に成立し、
したがって**任意の scaling path について** `ν(D_A) ≥ ν(Σ_A)`。
`F_Q = 4 D_A²|g(Δ)|²/Σ_A` と `χ = D_A g(Δ)` を代入すると

> **`ν(F_Q) < ν(χ)` ⟺ `ν(D_A) + ν(g) < ν(Σ_A)` ⟺ `ν(g) < ν(Σ_A) − ν(D_A) ≤ 0`**

**⇒ `ν(g) < 0`、すなわち probe optical coherence の減衰 `Γ_coh` 自体が `Γ→∞` で
消えること（保護された coherence）が必要条件である。**
**population の再配分だけでは、QFI は線形応答を漸近的に決して追い越せない。**

これは問題を凍結理論の protected kernel 機構（`ker D ≠ 0`、ガイド §4.2 no-go 6）へ
差し戻す。すなわち「非線形汎関数だから保護される」のではなく、
**保護の源泉はあくまで線形理論側の kernel 構造**である、という否定的だが明確な指針。

F6 で実際に宣言した path（sector レートを `a→Γa, b→Γb`）では
`ν(χ)=0, ν(Σ_A)=0` となり保護条件は成立しなかった（`Γ_coh` が base レートで固定のため、
上の必要条件から予想されるとおりである）。

## 6. 判定と次の選択肢

**ガイド §11.4 の収束判定に照らすと、本提案は「還元に成功した」に近い。**
ただし死んだのは中心命題の**書き方**であり、F8 の必要条件は新しい情報である。

| 選択肢 | 内容 | 評価 |
|---|---|---|
| (a) 撤回 | §6.4 の却下リストへ記録し、番号25 を欠番にする | F5 の論証（トモグラフィ完全性）は一般的で強く、正当な選択 |
| (b) 縮小継続 | 重心を F8 の必要条件へ移し、「QFI 保護には保護された coherence が必要」という**no-go 型**の主張にする | ただしこれは凍結理論の protected kernel 条件の言い換えに近く、L1 相当の懸念 |
| (c) 資源制限版へ移行 | 「線形汎関数に盲目」を「凍結予算内の protocol に盲目」へ置換 | P0-2（提案21/23）の領域と重複するため、§4.4 の予算と番号規約の観点で要検討 |

**現時点の推奨は (a) 撤回。** 理由は、F5 の「有限次元トモグラフィ完全性により
非線形汎関数階層は原理的に空」という論証が模型に依存しない一般論であり、
(b) の残骸は凍結理論の再言明に留まる公算が高いためである。
ただし最終判断は所有者が行う（ガイド §11.4）。

**残す資産（撤回する場合）:**

- **機構的必要条件:** 「QFI が線形応答を漸近的に追い越すには、probe coherence の
  減衰そのものが消えることが必要。population 再配分では不可能」（§5）
- **一般教訓:** 有限次元・トモグラフィ可能な設定で「非線形汎関数でのみ可視」を
  新規性の論拠にしてはならない。次に非線形 functional を狙うなら、
  **資源制限か無限次元のどちらかを同時に導入しない限り空**である
