### 2.1 W1a — 規約の同定（以降すべての土台）

単一行列要素のジャンプ `L_k = sqrt(g_k)|b_k><a_k|` に対し、参照準位 1 のコヒーレンス
`rho_{j1}` の減衰は閉形式

$$\Lambda_j \;=\; \tfrac12\bigl(\Gamma_{\rm out}(j) + \Gamma_{\rm out}(1)\bigr),
\qquad \Gamma_{\rm out}(l) := \sum_k g_k\,\delta_{l,a_k}$$

で与えられる。これが凍結された2つの witness を**厳密に**再現した。

- `prop:phase-n`: `D/Γ = diag(1/2, 13/20, 17/20, 21/20)` = 凍結値 `½diag(1,13/10,17/10,21/10)` ✓
- `prop:phase-h`: `D/Γ = diag(0, 0, 1/2)` = 凍結値 `diag(0,0,1/2)` ✓

**この一致により、以降の熱力学的拡張が凍結文書と同じ規約の上に載っていることが保証される。**

### 2.2 W1b — 熱的核持ち上げは恒等行列（`D_L = I`）

`prop:phase-h` に詳細釣合いの上向きジャンプ（KMS 比 `t = e^{−βΔ}`）を加えると

$$D(t)/\Gamma = \mathrm{diag}(t/2,\; t/2,\; 1/2 + t/2) \;=\; D_0 + \tfrac{t}{2}\,I .$$

上向きジャンプ `L = sqrt(g t)|4><1|` の `L†L = g t|1><1|` が**参照準位に載る**ため、
`rho_{j1}` の**すべて**に一律の減衰床 `Γ_out(1)/2` を与える。よって

- `t>0` で `dim Ker D = 0` ⇒ `P_full = 0` ⇒ `R_{S,0} = 0` ⇒ `ν ≥ 1`
- 持ち上げ行列は**恒等行列**であり、`ε = t/2 = ½e^{−βΔ}`

### 2.3 W1d — 斜交射影による反例

有限温度で `D` が正定値対角でも、斜交 Riesz 射影に対する圧縮は特異になりうる。
`Ran Π = span{u}`、`Ker Π = span{Du}` と取れば定義から `Π D u = 0`。
`t=1/5`、`D=diag(1/10, 3/5)`、`u=(1,1)` で明示構成した（`Π² = Π` を厳密に確認）。

このとき `eq:R0` の cut 項が生き残り `R_{S,0} ≠ 0`、すなわち **Class III が有限温度で成立する**。
凍結された `def:operational-sector` 自身が

**斜交性が本質である。**

## 3. 失敗の機構（記録すべき本体）

### 3.1 T1 — 仮定の読み違い

提案 L.164 は

> `ass:singular` の「半単純・非自明核」仮定は (E1)–(E2) の下で満たせない

と書くが、凍結された `ass:singular`（凍結 tex L.841）の原文は

> For each `j∈{full,cut}`, **either `0∉spec D_j`, in which case set `P_j=0` and `Q_j=I`**, or …
> If `P_j=0`, the corresponding protected contribution is defined to be zero.

であり、**核なしの場合を明示的に許容する仮定**である。プリミティブな有限温度 Davies 生成子は
これを破らず、満たす。

さらに提案の括弧内の理由づけ（「核1次元 ⇒ rank-1 射影 ⇒ full/cut 差が消える」）も、
`eq:R0` が `P_full` と `P_cut` を**別々に**持つため成立しない。両者が rank-1 でも
一般には異なるスカラーの差であって 0 にならない。

**正しい機構は W1b の減衰床である**：有限温度の詳細釣合いは、参照準位からの上向きジャンプを
必ず伴い、それが応答関連ブロックの**すべて**のコヒーレンスに一律の減衰床を与える。
そこから先は

- **T1(a)（漸近 no-go）** = 減衰床補題 ＋ **ガイド §4.2 赤線5**（full-rank strong damping no-go）
- **T1(c)（熱融解クロスオーバー）** = 減衰床補題 ＋ **ガイド §4.2 赤線7**（fixed kernel lifting no-go）

であり、いずれも既に赤線として明文化されている命題の適用例である。
新規なのは「`ε = ½e^{−βΔ}` かつ持ち上げ行列 `= I`」という**辞書**の部分のみ。

**一般化された教訓:** 有限温度の詳細釣合いは「核を持てない」のではなく、
**「参照準位に接続する逆過程が、応答ブロック全体に一様な減衰床を敷く」**。
no-go の担い手はスペクトルの縮退度ではなく、逆過程の存在である。

### 3.2 T1 — 仮定 (E3) が本質的（提案は装飾として扱っている）

提案は (E3) を「比較の対称性のため」と書く。しかし W1d の反例は、
(E3) を外すと**有限温度でも Class III が成立する**ことを示す。
(E3) は cosmetic ではなく **load-bearing** である。

ただし `rem:gksl-model` の但し書き（応答空間行列 `G_S` の形だけでは物理的 GKSL 生成子に
誘導されることの証明にならない）により、この斜交 `Π` を与える `G_S` が
GKSL admissible かは模型ごとの監査事項として残る。**本反例は線形代数レベルである。**

### 3.3 T2 — 担い手の置き場所が二重になっている

§2.4 の通り。`R_{S,0}` の担い手は `Ker D` の中（Γ減衰を受けない）でなければならないのに、
T2 は「Γ減衰を受けるコヒーレンス」を担い手に据えて下界を導こうとしている。
この矛盾は模型選択の問題ではなく、`ass:singular` と `eq:R0` の構造から来る。

**なお、これは提案23（WPOT）の死因と同型ではない。** WPOT は
「独立 source/readout の片側汎関数に熱力学的正値性が降りない」で死んだ。
T2 は片側汎関数であることに加えて、そもそも**下界の物理的機構が設定と食い違っている**。
片側性の問題（WPOT 型）は、機構を直したあとに改めて問う必要がある。**未解決のまま残る。**
