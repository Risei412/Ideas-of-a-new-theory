## 0. 結論

> **三準位 Λ 系では、吸収回復曲線は存在しない。分散回復曲線は存在するが、
> ac-Stark シフトによる分散零点へ厳密に還元される。
> したがって「吸収・分散回復点分裂」は三準位 Λ 系には存在しない（クラス D only、
> `Δ_split` は片側が空のため定義されない）。**

計算計画 §14 の生死判定表では **GO-1 は不成立**。§21 停止条件3
（「分裂が単なる detuning shift または既知のEIT linewidth式へ完全還元される」）が
**分散側で発火**した。

残る唯一の生存経路は **§14 GO-2（三準位 no-go ＋ 最小四準位 go）** である。
ただし下記 §4 の理由により、その見込みも当初より低い。

## 1. 何が計算されたか

三準位 Λ 系の GKSL Liouvillian（9次元）を記号的に構築し、
**真の定常状態を含めて** weak-probe 感受率を厳密に解いた。
規約テスト T0–T4 は全 PASS（trace/Hermiticity 保存、dephasing 規約、dark state 定常性、
凍結EIT §9.6 閉形式との一致、`Im χ > 0 = 吸収` の符号規約）。

得られた恒等式（全パラメータで厳密、証明書 P1–P3）:

**P1.** `Ω_p = 0` の定常状態は**厳密に `|g₁⟩⟨g₁|`**（全パラメータで）。

これは事前に想定していた最大のリスク（計算計画 §24.1 の「発見3」）を消した。
control は `g₂–e` のみを結び、崩壊は `e → g₁, g₂` の両方へ向かうため、
`g₁` は流出のない sink になる。**したがって optical pumping による population inversion は
三準位 Λ 系では起こらない。** 分岐比 `Γ₁/Γ_e` は `ρ⁰` に一切影響しない。

**P2.** よって凍結EIT §9.6 の閉形式は近似ではなく**厳密**である:

```
χ = (i/2)·γ_g / [ (γ_31 − iΔ_p)γ_g + β ],   γ_g = γ_12 − iδ,   β = |Ω_c|²/4
γ_31 = Γ_e/2 + γ_12/4        ← naive な Γ_e/2 ではない
```

`γ_31` に `γ_12/4` が乗るのは、ground-state dephasing `L_φ` が `ρ_{e g₁}` も減衰させるためである
（凍結理論の記述からは読み取れない実装レベルの事実。証明書の T4 で naive 版が不一致になることも確認）。

また `χ_∞ = lim_{β→∞} χ(β, γ_12=0) = 0` であり、この規約では `χ_dark = χ_∞ = 0`、
すなわち `Δχ̃ = χ` そのものになる。

**P3.** `χ = (i/2)γ_g·conj(D)/|D|²` を展開すると

```
Im χ の分子 = γ_31(γ_12² + δ²) + β·γ_12          （全単項式係数が正）
Re χ の分子 = −[ Δ_p(γ_12² + δ²) − β·δ ]
```

- **吸収回復条件** `Im χ = 0`：分子は `Γ_1, Γ_2, γ_12, Ω_c, δ` の多項式として
  **全係数が正**（`[1/2,1/2,1/2,1/2,1/4,1/4,1/4]`）。`γ_12 > 0` なら厳密に正。
  **⇒ 正の物理領域に解は存在しない。**
- **分散回復条件** `Re χ = 0`：`β = Δ_p(γ_12² + δ²)/δ`。`Δ_p/δ > 0` で正の解が存在する。

36点の exact パラメータスキャン（分岐比3×一光子離調4×二光子離調3、各5個の `β`）でも
`D only` 9点・`none` 27点、**`A only` と `D+A` は0点**であった。

## 2. 三問への回答（計算計画 §24）

**Q1（還元テスト）— 還元される。停止条件3 が発火。**
分散稜線 `β = Δ_p(γ_12² + δ²)/δ` は、`γ_12 → 0` で `β = Δ_p·δ` に帰着する。
これは制御場による ac-Stark シフトが二光子離調を打ち消して分散が零になる条件そのものであり、
`γ_12` はその位置に `O(γ_12²/δ)` の補正を与えるだけである。
**新しい回復則ではなく、既知の分散零点の `γ_12` 補正である。**
（凍結EIT §9.9 のクロスオーバー `y = |Ω_c|²/(4Γ_e γ_12)` とも別物で、
`y` はここでは稜線条件に現れない。）

**Q2（自己応答性テスト）— 受動性が吸収側を禁じる。**
`Im χ > 0` は三準位 Λ 系では構造的に強制される。
`docs/lkct-codimension-reality-audit.md` §6（Y7）が示した「CPTP は符号を強制しない」は
線形代数レベルでは正しいが、**EIT 弱プローブという具体的な GKSL クラスでは強制される**。
理由は Y7 の反例が `B_PP` 複素性に依存していたのに対し、ここでは
`ρ⁰ = |g₁⟩⟨g₁|`（P1）が `κ, α` に対応する係数の相対位相を固定してしまうためである。
監査 §6 の留保「GKSL 由来の `B_PP` が追加の構造を持つ可能性は排除されていない。
Step 2 で実際に導出するまで no-go 分岐を捨ててはならない」は**正しかった**。

**Q3（指数と分裂）— 分裂は定義されない。**
片側（吸収）が空集合であるため `r_disp − r_abs` は定義されない。
`(a,b)` の抽出も、分散側が既知零点へ還元される以上、単独では意味を持たない。

## 4. 四準位へ進むべきか

計算計画 §13 は「三準位で死んだ場合のみ四準位へ」と定めており、形式上は GO-2 の経路が残る。
しかし今回の死因は §13.1 のどの原因分岐にも素直に当てはまらない。

- **原因A（`κ, α` が同一直線上）ではない** — 分散側には正の解がある。
- **原因B（branching が符号を固定）でもない** — P1 により分岐比は `ρ⁰` に影響しない。
- 実際の死因は「**吸収の正値性そのもの**」であり、これは媒質の受動性に近い。

したがって四準位で吸収稜線を出すには、**population inversion（利得媒質）を作る必要がある**。
それは `Im χ < 0` の領域へ入ることを意味し、「理想 dark-state 応答への回復」という
元の問題設定から離れる。§13.2 の「一度に一仮定だけ壊す」規律とも緊張する。

**推奨:** GO-2 を追うなら、問いを「吸収回復曲線の存在」ではなく
**「受動性が吸収回復曲線を禁じる最小条件は何か」**（no-go の分類）へ組み替える。
これは提案24 §6 停止条件2 の再定義が用意している **PRL 分岐**に乗る。
ただしその主張を出すには、有限次元 GKSL の一般クラスで
`Im χ ≥ 0` がどこまで強制されるかを示す必要があり、
**それは三準位の計算では足りない**（今回示したのは Λ 系1クラスのみ）。
