## 1. 導出した4つの式

### [D1] ゼロ交差の統計的位置決め精度

稜線は `Φ(R−R_∞)` の符号反転として検出する。点あたり `N` ショット・相対雑音
`σ_rel = z*/√N` のとき、交差位置の不確かさは

```
δ(ln η) = σ_rel / S        S = 規格化傾き（U5 で厳密構成済み）
```

### [D2] 必要ショット数

交差を挟む2点（対数間隔 `±Δ`）の符号判定が `z*` σ で分離する条件から

```
N_min = z*² / (Δ² · S²)          — S² が厳密有理数なので N_min も厳密有理数
```

**実測（`z*=3`、`Δ=1/2`、格子 `Γ ∈ {1200,1500,2000,3000}`）:**

| Γ | R_Γ | S_Re | S_Im | N_min(Re) | N_min(Im) |
|---|---|---|---|---|---|
| 1200 | 8.4×10³ | 0.001452 | 0.003034 | 1.71×10⁷ | 3.91×10⁶ |
| **1500** | **1.05×10⁴** | **0.002695** | **0.002433** | **4.96×10⁶** | **6.08×10⁶** |
| 2000 | 1.4×10⁴ | 0.002489 | 0.001830 | 5.81×10⁶ | 1.08×10⁷ |
| 3000 | 2.1×10⁴ | 0.001863 | 0.001223 | 1.04×10⁷ | 2.41×10⁷ |

**傾きの構造が実用窓を存在窓より両側とも狭くする:** `S_Re` は生成閾値 `Γ_c ≈ 1170` で
**0 から立ち上がる**（交差の誕生は接根なので傾きが消える）、`S_Im` は `1/Γ` で減衰する。
最適点は `Γ = 1500`（`R_Γ ≈ 1.05×10⁴`）で、**最小予算 `N* ≈ 6.08×10⁶` shots/点**。

| 予算 N | 実用窓 |
|---|---|
| 10⁶ | **空**（観測不能） |
| 10⁷ | `Γ = 1500` 近傍で開く |
| 10⁸ | `Γ ∈ [1200, 3000]` の全格子で開く |

**FLOOR = 10⁻³（U5 の宣言値）の物理的正当化:** `FLOOR = z*/(Δ√N)` を解くと
`N = 3.6×10⁷` shots/点。すなわち U5 の床は**資源宣言と等価**であり、恣意的閾値ではなくなった。
`docs/lkct-visibility-audit.md` §8-3 の限界（床の物理的正当化が未了）はこれで解消。

### [D3] 背景オフセットの許容量

測定量 `M(η) = Φ(R−R_∞) + b` の零点は `δ(ln η) = b_rel/S` だけずれる。
許容シフト `Δθ_max = 1/4` から **`b_max,rel = S·Δθ_max`**:

| Γ=2000 | b_max,rel |
|---|---|
| Re | 6.22×10⁻⁴ |
| Im | 4.58×10⁻⁴ |

宣言した較正水準 `b̄ = 10⁻⁴` はこれを満たす。2交差は独立にずれるが、
各シフト `≤ 1/4 ≪ ln(比≈13) ≈ 2.6` なので**分裂の同定はオフセットに頑健**。

### [D4] 駆動強度分布と optical depth の翻訳

U6(a) の厳密則「稜線位置 `∝ λ²`」を使う。3点分布 `λ ∈ {1−δ_I, 1, 1+δ_I}`（`δ_I = 1/20`）の
**厳密平均応答**を Sturm 計数すると:

| 枝 | 窓内交差 | 相対シフト | 予測 `⟨λ²⟩−1 = 1/600` |
|---|---|---|---|
| Re | 1 個 | +0.00213 | 同桁 ✅ |
| Im | 1 個 | +0.00160 | 同桁 ✅ |

**optical depth への翻訳（導出）:** Beer–Lambert の場の減衰 `e^{−OD/2} ≥ 1−δ_I` ⇔

```
OD ≤ −2 ln(1 − δ_I) = ln(400/361) ≈ 0.103
```

薄い試料（`OD ≲ 0.1`）または局所強度で規格化した測定が条件。
**これは継承ではない** — λ² 則（本リポジトリの厳密結果）＋場の減衰の定義のみから導いた。

```
系        : 保護コヒーレンス2本以上（tripod / double-Λ 型）、基底コヒーレンス直接読み出し
動作点    : R_Γ = Γ_opt/γ_int ≈ 1.0–1.4×10⁴（最適 ≈1.05×10⁴）

ATS 対照  : control power を変えて稜線位置が λ² でスケールすることを確認（ATS は λ）
```

## 5. 本監査が行っていないこと（監査限界）

1. **集団・多体効果、検出器実装、高次スペクトル拡散は範囲外**（§3 の残余）。
2. **検出模型のパラメータ（`z*`、`Δ`、`Δθ_max`、`b̄`、`δ_I`）は宣言値**であり、
   特定の実験装置から導出したものではない。装置が決まれば置き換えて再実行する。
3. 走査格子は `Γ ∈ {1200,1500,2000,3000}` の4点。窓の端は格子分解能でしか決めていない。
4. **外部文献照合は未実施**（符号付き／実トロピカル幾何、egress 待ち）。
   **S1 の結論はこれで死ぬ可能性が残る。**
5. **A1（2小パラメータ特異摂動論への還元）は未決着**。赤チーム Stage 2 の対象。
