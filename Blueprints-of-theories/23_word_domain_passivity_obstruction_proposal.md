## 0. 結論

中心の問いは次の一つである。

> 有限次元 GKSL 系への介入語トランスクリプト `R(w)`（深さ ≤ n、凍結 shot 予算）から、
> 「このデータは**いかなる次元の**熱的（KMS/受動）浴とのカップリングによっても
> 生成され得ない」ことを**有限手続きで認証**できるのはいつか。
> その証明書は、calibration 部分データに対しては受動実現が**明示的に存在する**
> 入れ子構造と両立できるか。

理論固有現象を次のように置く。

> ### 【固有現象】次元自由受動排除（Dimension-Free Passive Exclusion / DFPE）
>
> 介入アルファベット `U`、語 `w ∈ U^{≤n}`、トランスクリプト
> `R(w) = Tr[E ℳ_w ρ₀]` に対し、一径数介入族 `u(θ)`（結合強度 `θ`、他は凍結）に
> 沿った**語領域 Loewner 行列**を
>
> $$\Pi_n[\theta_1,\dots,\theta_m]_{(w,i),(w',j)} := \frac{R(w\,u(\theta_i)\,w') - R(w\,u(\theta_j)\,w')}{\theta_i - \theta_j}$$
>
> の対称化として定める（対角は `∂_θ R(w u(θ) w')`）。このとき
>
> $$\boxed{\ \text{受動実現（任意次元）が存在する} \;\Longrightarrow\; \Pi_n \succeq 0
> \quad\text{（語領域受動性条件、Conjecture WP1）}\ }$$
>
> であり、逆に `λ_min(Π_n) ≤ -\varepsilon < 0` が凍結予算内で統計的に有意なら、
> **隠れ次元のいかなる値に対しても**受動的説明が排除される。
> 排除は「深さ n の語と m 点の θ 格子」という**有限データ**で完結し、
> かつ受動 ancilla の追加に対して**構造的に安定**（A2 閉性）である。

主張の骨格は3部からなる（logical status 付き）。

1. **WP1（語領域受動性条件）** — 受動実現 ⇒ `Π_n ⪰ 0`。 **Conjecture**。
   周波数領域では族Nの Loewner/NP 理論の帰結だが、語領域（有限深さ・非可換な介入合成）での
   成立は自明でない。Stage A スモークの検証対象そのもの。
2. **WP2（受動 ancilla 閉性）** — 受動系 ⊗ 受動 ancilla の縮約は WP1 の前提を保つ。
   **Conditional**（CIRT 定理C4 と同型。有限受動鎖 2000 例で反例なし、一般証明は未着手）。
   **これが偽なら理論は終わる**——7連敗の死因（shared-ancilla 逃避）が復活するため。
3. **WP3（入れ子違反構成の存在）** — calibration（深さ ≤ 2、θ 1点）では明示的受動実現を持ち、
   full（深さ ≤ 4、θ ≥ 3点）では `λ_min(Π) ≤ -ε` となる GKSL 介入対が存在する。
   **Conjecture**（逆設計の対象。P0-D の構成技法を流用する）。

## 1. なぜこの方向を選ぶのか

### 1.1 既存理論から引き継ぐ事実（ガイド §4）

- **RISEI** `def:protocol` — 介入語の概念と protocol-resolved propagator。
  補助仮定1つ（互いに素・固定長の窓）で `R(w) = Tr[E M_{w_k}⋯M_{w_1} ρ₀]` へ因子化する
  （derivability audit §1 の橋。**資産として残す**と明記されたもの）。
- **SMRT** — exact arithmetic による有限停止認証の方針。`Π_n` の固有値判定も
  有理数データ上の主小行列式判定として同じ流儀で書ける。
- **EIT no-go/go** — Schur complement 応答と「判定理論」というジャンルの前例。
  既知数学（ここでは Loewner 理論）の上に**新しい分類問題**を立てて認証された唯一の成功型。
- **P0-D 資産** — 入れ子証明書の設計文法、budget manifest、held-out 分離規約
  （`docs/p0-certificate-spec.md` §4.4–4.7 の凍結値をそのまま使う）。

### 1.2 壊す仮定 ← 新規性の源泉（ガイド §4.4 の7項目）

1. **外す仮定:** unrestricted representation criterion——「競合は任意の表現を許す」を外し、
   競合クラスを**熱的（受動）実現**に制限する。これは P0-2 の壊す仮定そのものであり、
   **外す仮定は1つ**（予算内）。
2. **維持する仮定:** 有限次元 time-local GKSL・固定比較クラス（初期状態・readout・窓・正規化）・
   weak-probe は**外さない**。介入は GKSL admissible に保つ（赤線1）。
3. **代替する数学的構造:** rank 階層（Hankel）→ **正値性 cone**（語領域 Loewner 行列）。
   決定的な差：rank 制約は次元 `D` で階層づけられ `D→∞` で空になるが、
   cone 制約は**次元一様**。「自由度を足せば消える」一般則（7連敗の機構）の適用外に立つ。
4. **失効する既存定理:** Huang et al. 2016 型の minimal realization 復元
   （一般位置 HMM 前提）は、競合クラスが受動実現に変わるため直接は適用されない。
5. **継承できる既存定理:** RISEI の Möbius 分解・比較規約、SMRT の exact 認証手続き、
   P0-D の calibration 恒等式構成。
6. **元の理論を回収する極限:** θ 格子を1点に潰す（`m=1`）と `Π_n` は定義されず、
   判定は P0-D の rank 証明書に退化する。また周波数分解能を無限に取る極限で
   WP1 は族Nの静的行列 NP 条件（Fei et al. 2021）に**回収されるべき**である
   （§3.5 の sanity check）。
7. **仮定変更が無ければ現象が消える control:** 競合クラスを「任意の GKSL ancilla」へ戻すと、
   排除は不可能になる（任意データが block-control 構成で実現可能——文献監査 P0-1 注記）。
   受動性制限こそが排除可能性の源泉であることを、gain を許した対照群で数値確認する。

### 1.3 7連敗の死因への応答

§6.4/§6.5 の全滅と derivability audit の結論は同一の一般則に従う：
**組合せ論的・代数的障害（格子・rank・余次元）は自由度追加で必ず消える。**
本提案の witness は代数的恒等式ではなく**凸錐の境界**である。
受動 ancilla を足しても cone は cone のまま（WP2）、非受動 ancilla を足すことは
「熱的説明」の放棄であり競合クラスからの退場を意味する。
逃避路が定義により閉じている——これが7回の失敗と構造的に異なる一点である。

## 2. 理論の定式化

### 2.1 定義

- **受動実現（passive realization）:** 系 `ℋ_S`（`dim = d < ∞`）と浴 `ℋ_B`（次元任意・可分）、
  全体 Hamiltonian `H = H_S + H_B + λ A_S ⊗ B`、浴状態は逆温度 `β_th ∈ (0,∞]` の KMS 状態
  （`β_th` は未知でよい。ただし語間で共通＝**浴は介入で変わらない**）。
  介入 `u(θ)` は系セクターのみに作用し `H_S` または `A_S` を `θ` だけ変形する。
  トランスクリプトは弱結合縮約後の `R(w)` として読む。
  記号注意（ガイド §5.3）：逆温度は `β_th` と書き、DIBT の `β_esc`・EIT の `β` と衝突させない。
- **語領域 Loewner 行列 `Π_n`:** §0 の boxed 定義。行・列は `(語 w ∈ U^{≤p}) × (θ 格子点)` の対、
  `n = 2p + 1`。`m` 点格子・語集合 `W` に対しサイズ `|W|·m`。
- **排除証明書:** 有理数化されたデータ上で `λ_min(Π_n) ≤ -ε` を主小行列式の符号列で示す
  exact 認証と、shot ノイズ下での片側固有値検定（§5.3）の対。

### 2.2 主定理（目標形、いずれも未証明）

- **定理候補 A（no-go）:** WP1 ∧ WP2 の下で、`λ_min(Π_n) < 0` なるデータは
  いかなる次元の受動実現も持たない。 **Conditional**（WP1, WP2 に条件付き）。
- **定理候補 B（分類）:** 固定した `(d, |U|, n, m)` に対し、受動実現可能なトランスクリプトの
  集合は閉凸錐の射影であり、その双対錐の生成元（dual witness）が有限個で書ける。 **Conjecture**。
- **定理候補 C（入れ子両立性）:** 「calibration 受動実現の存在」と「full 排除」は両立し、
  両立領域は測度正（開条件）。 **Conjecture**——P0-D の教訓（入れ子条件と余裕の反発、
  `PROJECT_STATE.md` 4bis）がここで再発しないかが最大の設計リスク（§6）。

## 3. 理論固有現象（ガイド §3 必須5項目）

### 3.1 固有現象の定義

§0 の boxed 命題（DFPE）。固有性の主張点は現象の「珍しさ」ではなく、
**証明書の論理型**にある：有限データ・凍結予算で**無限次元を含む仮説クラス全体**を排除する。
rank 型証明書（族D/A/E すべて）はこの型を原理的に持てない
（排除範囲が常に次元パラメータで打ち切られる——derivability audit §2 が実証した弱点）。

### 3.2 非還元性の証明または論拠

§4 で詳述。要点：witness の値域が cone 境界からの距離であり、
競合6族の null identity（rank・因子化・group-valued potential）のいずれとも型が異なる。

### 3.3 観測可能量（observable signature）

- 物理量：`λ_min(Π_n)`。負性は「閾値」型シグナルであり、θ 微分（有限差分）で構成できるため
  分光でなく**トランスクリプト統計のみ**から得られる。
- 検出手段：数値（custom Liouville、環境制約準拠）＋ exact 認証（SymPy 有理数）。
  実験としては駆動可能な少数準位系（回路QED の1トランズモン＋調整可能結合）で
  θ = 結合強度の 3–5 点掃引、深さ ≤ 4 語。shot 規模は P0-D 凍結値（214,000）から再見積もる。
- 有限サイズ・有限精度：negativity は開条件なので有限精度で可視（P0-D の厳密等式依存と対照的。
  RISEI `ass:robustness` に最初から適合する——fine-tuning 批判が構造的に無効）。

### 3.4 反証条件

- Stage A で受動鎖アンサンブルが `Π_n ⪰ 0` を**破る**（WP1 が偽）→ 理論は即死。
- WP2 の反例（受動 ancilla 追加で `Π` の負性が偽装できる）→ 即死。
- すべての違反構成が系側介入に gain（非 GKSL admissible な励起）を要する → 赤線1違反として撤回。
- 有意な負性が θ 格子の離散化誤差・shot ノイズと分離できない → (iii) 型の失敗として縮小。

### 3.5 既存理論との一致領域（sanity check）

- `m=1`（θ 1点）：`Π` 未定義、P0-D 判定に退化。
- 周波数分解極限（深さ・時間分解能 → ∞）：WP1 は族Nの静的 Pick 条件を再現**しなければならない**。
  再現しない定式化はどこかが誤り。
- 古典可換極限（全 `M_u` が同時対角化可能）：`R(w u(θ) w')` は θ の完全単調関数の混合となり、
  Loewner 行列の正値性は古典 Bernstein–Widder 理論に一致するはず（スモークで確認）。

## 4. 非還元性の検討

### 4.1 族D（HMM/線形実現・Hankel rank）——型が異なる＋構成で無害化

witness は正値性であり rank ではない。さらに WP3 の逆設計では **Hankel rank ≤ 6 を保ったまま**
`Π` の負性を出すことを設計条件に課す。すると族Dの識別子（rank）はこのデータに対して
何も主張せず、逆に P0-D 型証明書では本現象は不可視。相互に還元不能な直交軸となる。

### 4.2 族A（hidden ancilla GKSL）——**主戦場。定義により応答する**

族Aの ancilla が受動（KMS 浴の一部）なら WP2 で排除に含まれる。非受動な ancilla
（ポンプ・反転浴）は「熱的説明」ではないので、排除主張の外——**ただしこれは逃げではなく主張の内容**：
証明書が言うのは「この応答は熱平衡環境からは出ない＝環境に athermal 資源が必要」であり、
それ自体が物理的結論である。危険性は §4.7（athermality 証人の先行研究）で監査する。

### 4.3 族N（受動実現可能性・静的 NP/Löwner）——CIRT を殺した族。予算遮断＋語構造で差別化

族Nの全定理は「解析関数の点値（周波数領域データ）」の上に立つ。本提案のデータは
有限深さの介入語トランスクリプトであり、周波数データへの変換（スペクトル分解）には
凍結予算を大幅に超える時間分解能・語長が要る（P0-D で 43×43 Hankel が予算の20.25倍だった事実が
同型の障害）。**ただし最危険の還元先はここにある**：`Π_n` が有限語→モーメント写像を通じて
切断行列モーメント問題（Curto–Fialkow 型）の正値性条件の引き戻しに**過ぎない**なら、
本提案は族Nの時間域版として死ぬ。§4.8 で自己申告し、Stage B の kill test に最優先で置く。

### 4.4 族C（group synchronization、higher-order 含む）——group-valued potential が定義できない

witness は実対称行列の最小固有値であり、データは `[0,1]` 値トランスクリプトの θ 差分。
hyperedge potential への写像には group 値データが要るが、`Π` の負性は
**θ 方向の単調性構造の破れ**であって相対チャート `G_ij = X_j X_i^{-1}` の整合性とは変数の型が違う。
ただしガイド §6.5 の要件に従い、h=3,4 の higher-order baseline を実装した上での
kill test を Stage B に含める（構造的論証だけで免除としない）。

### 4.5 族B（tilted-GKSL/FCS）・族E（process tensor）——主張外を明示

FCS は生成側の道具であり排除側の主張と衝突しない。process tensor は任意データを表現できるが
「受動的に実現できるか」を問わないため、本提案の判定問題はその上に乗る（表現可能性 ≠ 実現可能性、
ガイド §4.3 最終項の区別そのもの）。

### 4.6 Frozen-Theories 3件——判定対象が異なる

RISEI/SMRT/EIT のいずれも浴の熱性を判定する定理を持たない。RISEI の弱点だった
「組合せ論的障害のみ」（CIRT §0 の診断）を補完する関係にあり、衝突はない。

### 4.7 物理側の先行研究（FDT/KMS 違反検定・athermality 資源理論）

熱平衡の検定として FDT 違反測定（aging 系・アクティブマター）と quantum thermodynamics の
athermality witness が既知。決定的な差分（の候補）：既知検定は**定常2点関数・周波数領域**を使い、
介入語の非可換合成・凍結有限予算・入れ子（calibration 側の明示的受動実現）の3点を持たない。
この差分が査読で立つかは文献監査 Pass 4（族T として新設）で先に潰す——**CIRT の教訓により、
逆設計に着手する前に実施する**。

### 4.8 最も危険な還元先（自己申告、§6.5 教材の形式）

1. **切断行列モーメント問題（Curto–Fialkow）への還元** — `Π_n ⪰ 0` が既知のモーメント正値性の
   言い換えなら、WP1 は新定理ではなく古典定理の翻訳になる。生き残る道は
   「非可換な語合成が入るため flat extension 理論が適用されない」ことの証明のみ。
2. **時間域受動性検定の先行研究** — 回路マクロモデリングの time-domain passivity
   （Grivet-Talocia 系列）、ハプティクスの passivity observer（Hannaford–Ryu 2002）。
   これらは**エネルギー収支（供給関数）ベース**であり Loewner 型ではないが、
   「時間域データから受動性を判定する」枠は既出。差分は量子介入語＋dimension-free 排除主張。
3. **単なる detailed balance 検定** — `Π` の負性が KMS 条件の周波数比検定と等価になる退化。

## 5. 検証計画（逆設計順序、ガイド §6.4 末尾に準拠）

**Stage A（null identity の固定）← 全てに先行。**
`scripts/cirt_c4_smoke.py` を語領域へ拡張した `scripts/wpot_null_smoke.py` を実装：
受動鎖（深さ1–5・各1000試行）で `Π_n ⪰ 0` を検査、対照群は gain / negweight / 系側 athermal 駆動の3種。
判定基準は実行前凍結（violation 率・最小固有値の下限）。**受動群で1件でも違反 → WP1 棄却・提案撤回。**
対照群で violation が出ない → 検定力不足として `Π` の定義を再設計。

**Stage B（kill test）:** §4.8 の3還元先を先に叩く。特に (1)：可換化した模型で `Π` 条件が
古典モーメント条件へ一致することを確認した上で、非可換模型での**差**を exact に分離する。
族C h=3,4 baseline の実装もここ。

**Stage C（逆設計）:** P0-D 構成技法で「calibration 受動・full 違反」の入れ子対を最適化探索
（ランダム試行は P0-D の教訓により最初から捨てる）。Hankel rank ≤ 6 拘束を同時に課す（§4.1）。

**Stage D（有限 shot）:** 判定は最初から統計的検定（`λ_min` の片側検定）で設計する——
P0-D の (iii) 失敗（作用素ノルム＋Weyl の2倍損）を繰り返さない。
held-out 規約・shot 予算は `p0-certificate-spec.md` の凍結値を継承し、
θ 格子点を setting として計上する（budget manifest を拡張）。

**Stage E（Stage 1 主張抽出 → ChatGPT 赤チーム）:** Stage A–B が GO の場合のみ。

## 6. 弱点と未解決点（弱点申告フォーマット準拠）

- **最も危険な既知還元:** 切断行列モーメント問題（§4.8-1）。次点で時間域受動性検定の先行研究。
- **最も弱い仮定:** WP1 そのもの（中心条件が Conjecture）。次に WP2（閉性）——
  スモーク証拠は有限受動鎖のみで、一般 KMS 浴では未検証。
- **最も脆い数値操作:** θ 有限差分（微分の離散化）と `λ_min` 推定の交絡。
  格子幅を凍結し、離散化誤差の解析的上界を証明書に含める必要がある。
- **最も不足している物理接続:** 弱結合縮約（GKSL 導出）と「浴は介入で不変」の整合性。
  系側介入が強いと縮約自体が θ 依存の浴相関を拾い、前提が壊れる。weak-probe 維持が効く範囲の明示が要る。
- **PRXを阻む一点:** WP1 が証明できず数値的 Conjecture に留まった場合、
  「判定理論」としての完結性（EIT 型の成功条件）を失い PRA 水準に落ちる。
- **stop condition:**
  1. Stage A で受動群violation > 0 → **撤回**
  2. WP2 反例 → **撤回**
  3. §4.8-1 の還元成立 → 族N後継として**降格**（CIRT と同じ出口。再提案禁止リストへ）
  4. 文献監査 Pass 4 で介入語構造まで含む先行研究発見 → **降格**
  5. Stage C で入れ子両立領域が測度ゼロ → 縮小（入れ子を外し PRL 型へ）
  6. Stage D で統計検定でも margin 不成立 → 縮小・実験提案のみ分離
