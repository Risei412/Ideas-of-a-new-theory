# 計画21: 分岐指数応答理論（Ramification Response Theory / RRT）

## 一行サマリ

保護核が**非半単純**なとき、応答汎関数の漸近 valuation は整数格子を離れ
`(1/ℓ)ℤ` 上に乗る。この**分数 valuation の分母 `ℓ`（分岐指数）** は、
振幅・Hankel rank・累積量のいずれにも現れない独立な操作的不変量であり、
既存の凍結三分類（`ν ∈ {∞} ∪ (0,∞) ∪ {0}`、保護深さは整数）を真に細分する。

**作成日:** 2026-07-26
**位置づけ:** 実行構成でも数値計画でもない。ガイド §6.1 の **P2「Nonsemisimple protected geometry」**
（壊す仮定：semisimple kernel）に対する理論設計図である。
P0（Hankel rank による資源下界）とは**直交する軸**を提案するものであり、置換ではない。
**判定:** 現時点で **PRX候補ではない**。理論固有性の中心的脅威（例外点 EP／Lidskii 摂動論）が
未解決であり、§4 の判定は **「還元リスク高。ただし kill test が短距離で実行可能」**。
PRL型またはPRA型に落ちる公算が現時点では大きい。§6 の stop condition を先に読むこと。

## 0. 結論

中心の問いは次の一つである。

> 凍結理論の保護定理はすべて **response-relevant protected cluster の半単純性** を仮定している。
> この仮定だけを外したとき、何が新しく現れるか。それは既知機構に還元されるか。

答えの候補を、理論固有現象として次のように置く。

> ### 【固有現象候補】分岐保護（Ramified Protection ／ 分岐保護）
>
> 有限次元 time-local GKSL の宣言経路 `A_Γ(z) = Γ·D_damp + B(z)` について、
> response-relevant protected kernel `ker D_damp` が**非半単純**（最大 Jordan block サイズ `ℓ ≥ 2`）
> であるとする。固定された比較規約（初期状態・probe・readout・観測窓・正規化）の下で、
> 応答汎関数の族 `Φ_p = ‖·‖_p` に対する漸近 valuation `ν_Φ` は、
>
> $$\boxed{\ \nu(s) \;=\; a \;-\; \frac{k}{\ell}\,s,\qquad s=\frac1p,\quad k\in\mathbb Z_{>0},\ \gcd(k,\ell)\ \text{任意}\ }$$
>
> という**分母 `ℓ` の分数傾き**を持つアフィン則に従う。すなわち幅指数 `z` は整数格子を離れる。
>
> 対して、`ker D_damp` が半単純である限り（凍結理論の仮定内では常に）、`z ∈ ℤ` である。
>
> **`ℓ` を「分岐指数（ramification index）」と呼ぶ。`ℓ ≥ 2` は、振幅 valuation・
> Hankel rank・低次累積量のいずれにも痕跡を残さない。**

したがって主張は次の形になる。

1. **細分主張（分類）** — 凍結三分類 `ν ∈ {∞} ∪ (0,∞) ∪ {0}` の「positive finite」枝は、
   `ν` の**分母**によってさらに層別される。凍結理論はこの層を見ていない。
2. **不可視性主張（非還元性の入口）** — `ℓ` は amplitude valuation に現れない（§3.3 で数値確認済み）。
   よって Hankel rank／moment hierarchy を尽くしても `ℓ` は復元されない。
3. **有限窓主張（正直な限界）** — `ℓ ≥ 2` は非生成的（codimension を持つ）。
   Jordan構造を `ε` で持ち上げると `Γ ~ ε^{-ℓ}` で crossover する（§3.3 で数値確認済み）。
   **したがって本提案は無条件の漸近相を主張しない。** 主張は
   「対称性で Jordan構造が保護されている場合の漸近則」または
   「二重スケーリング変数 `Γ ε^{ℓ}` 上の collapse 則」のいずれかに限定される。

## 2. 理論の定式化

### 2.1 型の宣言（ガイド §2）

- **型:** **(B) 数学的定理型 + (A) 現象論的理論** の複合 → **(D) 統合型**。
  ただし重心は (B)：分類定理（valuation の分母による層別）と、その操作的 witness。
- **対象系:** 有限次元・開放系・量子（time-local GKSL）。無限次元・非Markov・多体極限は扱わない。
- **対象スケール:** 支配的散逸スケール `Γ` の漸近域。周波数窓 `K ⋐ Ω^{SMRT}` は固定。
- **想定読者:** 開放量子系、非Hermitian物理、数理物理（摂動論・特異摂動）、量子光学。

### 2.2 記法（ガイド §5.3 の衝突回避）

衝突記号を無修飾で使わないため、本提案では次を固定する。

| 記号 | 意味 | 備考 |
|---|---|---|
| `D_damp` | fast damping-shape operator（`A_Γ(z) = Γ D_damp + B(z)`） | ガイド §5.3 に従い `D_hidden` と書き分ける |
| `ℓ` | **分岐指数** = `D_damp` の零固有値に属する最大 Jordan block サイズ | 新規記号。§5.2 へ追記対象 |
| `𝔏` | Jordan chain の集合（`ker D_damp` 上） | 新規記号 |
| `ν_Φ(s)` | 汎関数 `Φ` 依存 valuation、`s = 1/p` | RISEI から継承 |
| `a` / `z_w` | 高さ指数 ／ **幅指数** | 計画18の `z` は RISEI の `z_loss`, `z_jet` と衝突するため `z_w` と改名 |
| `K_win` | 観測窓 | SMRT の `K ⋐ Ω` は RISEI `K_Z`・EIT `K_ab` と衝突するため改名 |
| `𝒫_ram` | ramified branch へのcontour射影 | 半単純核の Riesz 射影 `P_𝒞` の代替物 |

### 2.3 定義

**定義 2.1（分岐指数）**
`D_damp` の零固有値に付随する Jordan 標準形のブロックサイズの最大値を `ℓ := ℓ(D_damp)` と定める。
`ℓ = 1` は半単純核に一致する。

**定義 2.2（response-relevant ramification）**
固定された source `c` と readout `p†` に対し、`𝒫_ram c ≠ 0` かつ `p† 𝒫_ram ≠ 0` であり、
かつ Jordan chain の長さ `ℓ` の部分が projected source/readout と非零に重なるとき、
`ℓ` は **response-relevant** であるという。
以下の主張はすべて response-relevant な `ℓ` についてのみ述べる。

**定義 2.3（分数 valuation）**
汎関数 `Φ` と観測窓 `K_win` に対し
`ν_Φ := -\lim_{Γ→∞} \log Φ(R_Γ) / \log Γ`（存在するとき）とし、
`ν_Φ ∉ ℤ` のとき valuation は **ramified** であるという。

### 2.4 主張（logical status を明示する）

> **主張 R1（分岐則 / status: Known mathematics — 本提案の新規性ではない）**
> pencil `Γ D_damp + B` の固有分岐は Puiseux 展開を持ち、その指数の分母は
> `ker D_damp` の Jordan block サイズを割る。したがって固有値は `Γ^{k/ℓ}` の形で分岐する。
>
> これは Lidskii 型摂動論（Lidskii 1966; Moro–Burke–Overton 1997）として既知である。
> **本提案は R1 を新規結果として数えない。** §3.3(1) の数値はサニティチェックにすぎない。

> **主張 R2（振幅盲目性 / status: Numerical phenomenon → 要証明）**
> 固定された `p†, c` に対するスカラー応答 `R_Γ = p† A_Γ^{-1} c` は `Γ` の有理関数であり、
> その valuation は**常に整数**である。すなわち `ℓ ≥ 2` は振幅 valuation に痕跡を残さない。
>
> 有理性そのものは自明（Cramer 則）。非自明なのは
> **「したがって moment hierarchy／Hankel rank を尽くしても `ℓ` は復元できない」**という
> 情報論的帰結であり、これは未証明である。§4.5 参照。

> **主張 R3（分数ファン則 / status: Conjecture + Numerical support）**
> response-relevant な `ℓ ≥ 2` の下で、`Φ_p = ‖·‖_p` 族に対し
> `ν(s) = a - (k/ℓ)·s`（`s = 1/p`）が成り立つ。**幅指数 `z_w = -k/ℓ` は分数である。**
>
> 数値支持は §3.3(2)（`ℓ=2` で `z_w = -0.500`、4点が直線上）。
> **一般証明は未着手。** 現時点で得られている論拠は、計画18 §0 の形状引数
> （`‖R‖_p ∼ h·w^{1/p}` → `ν(s) = a + z_w s`）に、R1 由来の
> 「特徴幅 `w ∼ Γ^{-k/ℓ}`」を代入したものにすぎない。
> **形状引数は単一特徴・固定形状を仮定しており、分岐した複数枝が窓内に共存する場合には成立しない。**
> これが R3 の最大の穴である。

> **主張 R4（分岐指数の資源下界 / status: Conditional theorem — 要証明）**
> 観測データから `ℓ` が確定したとする。**同一の宣言経路について、
> 制御変数 `Γ` がアフィンに入る（`Γ D' + B'`）任意の有限次元実現**は、
> その `D'` の零固有値に少なくともサイズ `ℓ` の Jordan block を持たねばならず、
> したがって実現次元 `N` は `N ≥ ℓ` を満たす。
>
> **この下界は弱い。** 族A（`d·D_hidden ≤ 12`）を排除するには `ℓ ≥ 13` が要り、
> 現実的でない。**したがって R4 を P0 の代替経路として売ってはならない。**
> R4 の価値は下界の大きさではなく、**`ℓ` が rank とは独立な不変量**である点にある（§4.5）。

> **主張 R5（二重スケーリング crossover / status: Numerical phenomenon）**
> Jordan構造を `ε` で持ち上げると、分数 valuation は `Γ ≲ ε^{-ℓ}` の窓でのみ観測され、
> それを超えると整数 valuation へ crossover する。すなわち
> **`ℓ ≥ 2` は無条件の漸近相ではなく、二重スケーリング変数 `x_ram := Γ ε^{ℓ}` 上の相である。**
>
> §3.3(4) で crossover の存在は確認した。`x_ram` 上の collapse は未検証。
> **これはガイド §6.1 の P1「Exact-to-approximate kernel crossover」と同じ構造であり、
> 本提案はその空白地帯へも副次的に接続する。**

## 3. 理論固有現象（ガイド §3 必須項目 1〜5）

### 3.1 固有現象の定義

§0 の boxed 命題（分岐保護 / Ramified Protection）。

### 3.2 非還元性の論拠 → **§4 に分離する**（本提案の最大の争点であるため）

### 3.3 観測可能量（observable signature）と数値スモーク

**測定量:** `ν(s)` の**傾き `z_w`**。すなわち複数の `p` について `‖R_Γ‖_p` の
`Γ` 依存指数を測り、`s = 1/p` に対する直線の傾きを取る。
**分母 `ℓ` は、この傾きの有理数としての分母として読み出される。**

- **形の現れ方:** 発散でも不連続でも閾値でもなく、**valuation 格子の細分**として現れる。
  half-integer 傾きは semisimple 凍結理論では出せない。
- **検出手段:** 数値（pencil の resolvent を窓上で走査、log-log fit）。実験へは §5.3。
- **有限精度で見えるか:** `ℓ = 2` の判別（`z_w = -1/2` vs `0` vs `-1`）は
  1桁の `Γ` あたり 0.5 decade の分離を与えるため、粗い測定でも判別可能。
  `ℓ = 3` 以上（`-1/3` vs `-1/2`）は 3〜4桁の `Γ` レンジと fit-window 収束報告を要する。

**予備スモーク（`scripts/ramification_smoke.py`、numpy のみ、seed 11、`n=3`）**

実装は `A_Γ(z) = Γ D_damp + B + i·ω·I`、`R(ω) = p† A^{-1} c`。
`D_damp` は (i) 零固有値に J2 + 高速方向1本（非半単純核）、(ii) 同じ核次元の半単純 control。

### 3.4 反証条件

本理論は次のいずれかが成立した時点で棄却または大幅縮小される。

1. **`z_w` が常に整数** — 非半単純核を持つ GKSL 生成子の族について、
   格子収束・窓収束を取った `ν(s)` の傾きが整数に収束する例が支配的であること。
2. **半単純 control が同じ傾きを出す** — §3.3(3) の destruction control が破れること。
3. **`ℓ ≥ 2` が GKSL admissible な `D_damp` では実現不能** — Kossakowski 行列の PSD 性が
   damping-shape operator の半単純性を強制すること。**これは実際に起こりうる。** §6 の最大リスク。
4. **分数指数が EP 機構と操作的に区別できない** — §4.1。
5. **`ν(s)` が直線でない** — 分岐した複数枝が窓内に共存し、`Φ_p` が単一特徴則に従わない場合。R3 が死ぬ。

### 3.5 既存理論との一致領域（sanity check）

- `ℓ = 1` で SMRT の整数次数公式・排他的三分類・保護チャネル `Γ⁻¹` 展開が完全に回復する（§1.2-6）。
- §3.3(1) の半単純 control で分岐指数が `{0, 0, 1}` となり、
  凍結理論の「slow cluster は `O(1)`、fast は `O(Γ)`」という描像に一致する。
- `ε` を大きく取れば §3.3(4) は整数枝へ戻る。

## 4. 非還元性の検討

**結論を先に書く。§4.1 は現時点で未突破である。本提案は「非還元性を主張できる状態にない」。**

### 4.1 【最大の脅威】例外点（EP）／非Hermitian摂動論への還元

- **脅威の内容:** `Γ^{1/2}` 分岐は例外点の教科書的signatureである。
  ガイド §3.1 は「既存の一般的機構（Zeno効果、**例外点**、FCS、…）」への還元検査を要求している。
  さらに主張 R1 は Lidskii 摂動論そのものであり、**新規性は R1 にはない**。
- **本提案が主張しうる差分（未確立）:**
  1. EP の標準的な文脈は「パラメータを degeneracy へ**近づける**ときの分裂 `∝ ε^{1/2}`」であり、
     sensing への応用が主眼である。本提案は「**degeneracy に留まったまま、
     宣言された散逸スケーリング経路 `Γ→∞` に沿った応答汎関数の valuation**」を対象とする。
     tuning ではなく asymptotics であり、測定量は分裂幅ではなく `p`-ノルム valuation の傾きである。
  2. EP文献は固有値・固有ベクトルの幾何を扱い、
     **固定された比較クラス（source/readout/窓/正規化）の下での full-minus-cut 差分**という
     RISEI/SMRT の操作的対象を扱わない。
- **正直な評価:** 上記1・2はいずれも「文脈が違う」という主張であって、
  **数学的に還元されないことの論証ではない。** EP 摂動論から `ν(s) = a - s/ℓ` を導けるなら
  本提案は死ぬ。**その導出は容易である可能性が高い。**
- **kill test（最短・実行可能）:** 標準的な EP 摂動展開（Puiseux + 形状引数）だけから
  §3.3(2) の4点を予測できるか。予測できたら §6.4 却下表へ移す。**これを最優先で実行すべきである。**

### 4.2 族D（controlled HMM / 有限線形実現）・族A（hidden ancilla GKSL）

- 主張 R2 により、`ℓ` は**振幅 valuation にも Hankel rank にも現れない**。
  したがって「Hankel rank ≤ 6 の実現が存在する」ことは `ℓ` を再現することを意味しない。
  逆に言えば、**族D・族Aは `ℓ` について何も言っていない**。
- ただしこれは非還元性ではない。**族Dが `ℓ` を再現できるかは別問題**であり、
  R4 が示すのは「アフィンに `Γ` が入る有限次元実現は `N ≥ ℓ` を要する」だけである。
  `ℓ = 2` なら `N ≥ 2` — **何も排除しない。**
- **したがって族D・族Aに対して本提案は現時点で優位を持たない。**

### 4.3 族B（tilted-GKSL / FCS）

- 本提案の witness は累積量ではなく `p`-ノルム valuation であるため、
  FCS の有限次微分階層に直接は写らない。ただし FCS 側の生成子も pencil であり、
  非半単純核を持てば同じ分数指数を出す。**FCS は競合ではなく、同じ現象の別表示になりうる。**
- **kill test:** tilted 生成子 `L_s` の damping-shape に同じ Jordan構造を入れ、
  累積量の valuation が同じ分母を持つか確認する。持つなら「FCS内の例」として格下げ（§6.4 の
  protocol-order fluctuation と同じ死に方）。

### 4.4 族C（compact-group synchronization、hyperedge order `h=3,4` 込み）

- 本提案には chart / gauge / relative frame が存在せず、
  witness は単一の実数指数である。`context-pack.md` §6.2(c) の規定により **N/A** と判定してよい。
- **これは §6.5 の4候補がすべて死んだ死因（pairwise relative-chart 因子化）を
  構造的に回避している唯一の点である。** 本提案の数少ない積極的な利点。

### 4.5 族E（bounded-memory process tensor）と P0 との独立性

- P0 の証明書は**容量**（Hankel rank ≥ 7、`dim K > 144`、OSR ≥ 37）である。
  本提案の証明書は**分母**（`ℓ ≥ 2`）である。R2 が正しければ両者は独立な不変量であり、
  一方の証明書は他方について何も含意しない。
- **`docs/p0-certificate-spec.md` §1 の「入れ子」原則を本提案に写すなら:**
  calibration 側で「分母1（整数 valuation）の競合が存在する」ことを示し、
  full 側で「分母が `ℓ ≥ 2` である」ことを示す構造になる。
  ただし §4.2 のとおり、分母を上げても競合の次元制約はほとんど効かない。
  **入れ子は形式上作れるが、資源分離としては弱い。**

### 4.6 凍結理論（`Frozen-Theories/`）との関係

- SMRT の三分類は `ν ∈ {∞} ∪ (0,∞) ∪ {0}` であり、`ν` が分数であること自体は禁じていない。
  **凍結定理と矛盾しない。** 矛盾するのは「次数公式 `ν = deg_Γ Q_S − deg_Γ N_S` が整数を与える」
  という含意であり、これは半単純性仮定に依存している。§1.2-4 で失効定理として列挙済み。
- ガイド §4.2 の赤線との照合:
  - 赤線5（full-rank strong damping no-go）— `D_damp` は特異なので抵触しない。
  - 赤線6（protected response の必要条件は半単純核）— **本提案はこれを意図的に外している。**
    外した以上、protected response の主張は継承できない。新しい必要条件を §2.3 定義2.2 で置いた。
  - 赤線7（fixed kernel lifting no-go）— §3.3(4) が正面から対応する領域。
    **本提案は無条件の漸近相を主張しない**ことで抵触を回避する。
  - 赤線10（極限交換禁止）— `Γ→∞` と `ε→0` の順序が本質。`x_ram = Γ ε^ℓ` を明示する。

### 4.7 却下リストとの照合（ガイド §6.4）

6件のいずれとも機構が異なる（contextuality gluing / order fluctuation / relative gauge /
quotient atlas / cycle atlas / ternary irreducible response）。**再提案には当たらない。**

## 6. 弱点と未解決点（ガイド §8 の申告フォーマット）

- **最も危険な既知還元:** **例外点（EP）／Lidskii 型非Hermitian摂動論。**
  `Γ^{1/ℓ}` 分岐は既知であり、主張 R1 は新規性を持たない。
  新規性は「操作的 valuation 則 R3」と「分類の細分」に限られるが、
  それが EP 摂動論から一行で出る可能性が高い。**§5.1 A1 で最初に検査すべき。**

- **最も弱い仮定:** **`ℓ ≥ 2` が GKSL admissible な damping-shape で実現できること。**
  Kossakowski 行列の PSD 性が `D_damp` に強い構造を課すため、
  **非半単純な `D_damp` が物理的に許されるか自体が未確認である。**
  現行スモークの `D_damp` は物理模型から出ていない。

- **最も脆い数値操作:** (i) 周波数格子（40001点で 9% ずれ）、
  (ii) 窓則 `W = 5Γ^{0.6}` の恣意性、(iii) log-log fit の window 依存、
  (iv) §3.3(4) の crossover が予測より1〜2桁早い点。

- **最も不足している物理接続:** 実装・材料・SNR がすべて未接続。
  `Γ` を 3〜4桁振る実験手段が不明。matched interface も未定義。

- **PRXを阻む一点:** **非還元性が未証明であるにもかかわらず、
  中心機構が既知（EP）と同型に見えること。** 現状では desk rejection 相当。
  仮に §5.1 を生き延びても、R4 の資源下界が弱いため
  「単一模型で珍しい指数が出た」（ガイド §1.1 が明示的に弱いとする類型）に留まるリスクが高い。

- **stop condition:**
  1. §5.1 A1 で EP 摂動論から R3 が導けたら → **即座に §6.4 却下表へ**（番号21は欠番として残す）
  2. §5.1 A2 で GKSL admissible な `ℓ ≥ 2` が構成できなければ → **理論が空。撤回**
  3. A3 で族Bが同じ分母を出したら → **FCS内の例へ格下げ**（固有現象としては死）
  4. B1 で `ν(s)` が直線でないと判明したら → 中心命題 R3 を撤回し、分類主張のみに縮小
  5. B6 で対称性保護された Jordan構造が見つからなければ → 主張を**有限窓 crossover 則**へ縮小し、
     投稿先を PRA/PRB へ降格（ガイド §1.2 の降格条件「full physical model では現象が観測不能」に接近）
  6. 3ラウンド以上「まだ検討が必要」が続いたら → ガイド §11.4 に従い打ち切り

- **提案自身の自己評価（ガイド §3.2 の固有性階層）:**
  現時点で **L2**（既存枠組みでは自然に出ないが、原理的には導出可能）。
  **L3 を主張していない。** §5.1 A1 を通過して初めて L3 の候補になる。
