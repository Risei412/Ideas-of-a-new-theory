# 錐検閲応答理論（Cone-Censored Response Theory / CCRT）
## 一行サマリ

母集団を保存する GKSL 切断のレートプロファイルは squared-Euclidean（条件付き負定値）錐に閉じ込められる。この「実装錐」が、凍結理論群が自由パラメータとして扱ってきた sector 切断 counterfactual の一部（単一コヒーレンス切断を含む）を**資源無制限でも実装不能**にし、SMRT のスケーリング経路に**経路検閲指数 q\*** という新しい操作的境界を与える。

**作成日:** 2026-07-29
**位置づけ:** 型 (D) 統合型（中心は型 (B) no-go 定理 ＋ 型 (A) 検閲ギャップの現象論）。対象系は有限次元・time-local Markovian GKSL（凍結理論と同一）。想定読者は開放量子系・量子光学・量子情報。ガイド §6.1 の **P0「Interface realizability」**（壊す仮定: ideal cut primacy）を占有する。提案19（CIRT、降格済）・提案23（DIBT）と同じ空白地帯だが、周波数領域受動性（CIRT の死因）にも語領域データ（DIBT/WPOT の領域）にも依存しない、**生成子データそのものの錐制約**という別ルートを取る。
**判定:** Stage 0。中核の錐補題と検閲の存在は本日付の厳密スモーク（`scripts/ccrt_cone_smoke.py`、S1–S6 全PASS、判定に float 不使用）で確認済み。固有性の自己評価は **L2–L3**（錐そのものは既知数学の輸入。応答理論への帰結 κ\*・q\*・検閲ギャップが新規性の重心）。kill test は短距離で実行可能。PRX を名乗る前に §6 の stop condition を全て通すこと。

## 0. 結論

**中心の問い:** 凍結理論（RISEI・SMRT・EIT）の全結果は「sector 切断generator 𝒢_S のレートは自由パラメータ」という前提で計算されている。では、**そのレートプロファイルのうち、実際に GKSL 介入として実装できるのはどの部分か。** 実装できない counterfactual に対して凍結理論が返す分類・予言は、操作的に何を意味するのか。

**理論固有現象（boxed）:**

> **切断検閲（cut censorship）.** 有限次元 time-local GKSL 系で、系の全ての母集団（対角成分）を保存しながら sector コヒーレンスを減衰させる介入 generator のコヒーレンス減衰プロファイル `γ^{cut}_{jk}` は、**条件付き負定値（cnd）錐 𝒩 に属するものに限られる**（jump 作用素の数・対角 ancilla 資源によらない）。したがって:
>
> 1. **絶対検閲:** 単一コヒーレンス切断（ある1ペア (j,k) のみ `γ^{cut}>0`、他ペア 0）は n≥3 で `𝒩` の外にあり、**いかなる資源でも単独では実装できない**（厳密確認済み、S3）。
> 2. **強度検閲:** 背景散逸 𝒢₀ が cnd 部分に内部点を持てば、検閲された切断パターン δ も合成 `𝒢₀ + κδ` としては `κ ≤ κ*(𝒢₀, δ)` まで救済される。κ\* は一般化固有値問題で厳密に計算できる（n=3・一様床で κ\*=3 を厳密確認、S6）。
> 3. **経路検閲:** SMRT のスケーリング経路 `κ = κ₀Γ^q` は、背景床が Γ に比例するとき **q > q\* = 1 で漸近的に錐から出る**。q\* を超える経路上の ideal-cut counterfactual は操作的に空であり、操作的応答は ideal 予測から**計算可能な検閲ギャップ**だけ乖離しなければならない。

対照（ablation）: 実装制約を外し「任意の線形散逸子」を許せば検閲は恒等的に消える（S5）。すなわち現象は壊した仮定（ideal cut primacy）の産物であり、他の仮定からは出ない。

## 1. なぜこの方向を選ぶのか

### 1.1 既存理論から引き継ぐ事実

- **SMRT**（凍結）: master sector-resolved response `ℛ_S`、経路仕様 `𝔓=(𝒢_S, κ₀, q)`、valuation `ν_S(q;κ₀)` の排他的三分類。本提案はこの分類を**書き換えない**。分類の**操作的定義域**（どの (𝒢_S, κ₀, q) が実装可能か）を追加する。
- **RISEI**（凍結）: 物理的介入は generator 全体を GKSL admissible に保つ（ガイド §4.2 赤線1）。本提案はこの赤線を定理の形に精密化したものと言える — 「admissible に保てる切断パターンは cnd 錐で完全に特徴づけられる」。
- **EIT no-go/go**（凍結）: `δχ_S = χ_full − χ_cut^(S)` の cut counterfactual。cut が bipartition 型（2グループ間の全コヒーレンスを一様に切る）なら cut metric は ℓ₁ 埋め込み可能で錐の内部にあり、既存結果は無傷で継承される（§3.1-5 の一致領域）。
- **計画20（TPR）段階1の資産:** 減衰床補題 `Λ_j = ½(Γ_out(j)+Γ_out(1))`。減衰床核 `K^{floor}_{jk} = ½(Γ_j+Γ_k)` は cnd（和型核は零和ベクトル上で消える境界元）であり、強度検閲 κ\* の「背景」を凍結理論の言葉で供給する。
- **Memory-Accessibility-Theory リポジトリ（外部コーパス、活動中）:** G2 傾き量子化（傾き = 消滅モーメント数 ≤ rank−1、証明済）、G3 縮約定理（可換モノミアル対称性下で上昇傾き = 指標 Cayley 語長、証明済）。§3.3 の検閲窓はこの語長則の GKSL 実装可能性を問う形で接続する（G3 §6-2 が未着手と明記する「複数軌道」拡張が必要になる）。

### 1.2 壊す仮定（新規性の源泉）

**壊す仮定はひとつ: ideal cut primacy** — 「sector 切断generator のレートプロファイルは自由パラメータであり、任意のプロファイルの counterfactual が操作的意味を持つ」。

これを次で置換する: 切断は**宣言された実装クラス**（系の register 上の time-local GKSL、母集団保存）の元でなければならない。counterfactual の比較クラス（初期状態・probe・readout・観測窓・正規化）は凍結理論と同一に保つ（赤線2遵守）。

**維持する仮定:** 有限次元、time-local Markov 性、weak probe、固定比較クラス、semisimple 性の扱い、極限順序の規律 — すべて凍結のまま。§4.4 の予算内（壊すのは1つ）。

**仮定変更がなければ現象が消える control:** S5。自由レート散逸子のクラスでは任意の正プロファイルが許され、検閲・κ\*・q\* はすべて空語になる。

**P0-1 の凍結ラベル（`context-pack.md` §6.2.2 への応答):** 本提案は C-JOINT / I-JOINT（既知還元の公算大とされた2つ）ではない。**新ラベル IMPL-CONE** を提案する: 「与えられた系の上で、宣言された介入クラス（time-local GKSL・母集団保存）に属する実装が存在するか」。R-BOUND と異なり資源上限に依存しない（錐は埋め込み次元・jump 数について閉じている）ため、文献監査が警告した「無制限資源で常に構成できるので非自明にならない」という空虚化が**構造的に起きない**。これが CIRT・DIBT と本提案の決定的な立ち位置の差である。

## 2. 理論の定式化

### 2.1 記法（衝突回避の宣言）

ガイド §5.3 の衝突記号のうち、本文書では `q`（SMRT 経路指数、SMRT の意味で使用）、`ν`（SMRT valuation、同）以外は使わない。新出記号:

| 記号 | 意味 |
|---|---|
| `γ^{cut}_{jk}` | 切断のコヒーレンス減衰プロファイル（対称・対角零・非負） |
| `𝒩` | 実装錐（implementation cone／実装錐）: n点上の cnd 核の錐 |
| `ζ_j ∈ ℂ^m` | 脱位相埋め込み（dephasing embedding）: jump 作用素 `L_m = diag(z^{(m)})` の列 `ζ_j = (z_j^{(1)},…,z_j^{(m)})` |
| `Gram(γ)` | 基点固定の (n−1)×(n−1) Schoenberg Gram 行列 |
| `κ*(𝒢₀, δ)` | 検閲強度上限（censorship strength bound／検閲強度上限） |
| `q*` | 経路検閲指数（path censorship exponent／経路検閲指数） |
| `Δ_cens` | 検閲ギャップ（censorship gap／検閲ギャップ）: 操作的応答と ideal-cut 応答の乖離下界 |

### 2.2 定義

**定義1（母集団保存切断）.** 系 Hilbert 空間の宣言基底 `{|j⟩}` に対し、介入 generator `δ𝒢` が母集団保存であるとは、全ての状態 ρ で `(δ𝒢 ρ)_{jj} = 0` が成り立つこと。これは「sector コヒーレンスを殺すが占有数を動かさない」切断の操作的定義であり、凍結コーパスの dissipative sector cut の標準的意図に一致する。

**定義2（実装錐）.** `𝒩 = { γ 対称・対角零 : Σ_{j,k} x_j x_k γ_{jk} ≤ 0, ∀x∈ℝ^n, Σx_j = 0 }`（条件付き負定値錐）。

### 2.3 補題と定理

**補題1（対角性の強制）— Exact（S1で恒等式として確認、証明は1段落）.**
母集団保存の time-local GKSL generator は、jump 作用素がすべて宣言基底で対角、Hamiltonian 部分が対角と可換なものに限る。
*証明の骨子:* ρ=|m⟩⟨m| に対する散逸子の対角成分は `Σ_k |⟨j|L_k|m⟩|²`（j≠m）で、非負項の和。全て零 ⟺ 全 jump の全非対角成分が零。∎

**補題2（錐の特徴づけ）— Exact（既知数学の輸入であることを明示）.**
対角 jump `L_m = diag(z^{(m)})` の GKSL 散逸子はコヒーレンスに `γ_{jk} = ½‖ζ_j − ζ_k‖²` の減衰を与える（squared-Euclidean 核）。逆に任意の `γ ∈ 𝒩` は Schoenberg 埋め込みにより有限個の対角 jump で実現できる。すなわち **母集団保存 GKSL 切断のプロファイル全体 = 𝒩**。
*status:* この対応は Schoenberg（1938）の古典定理と、Schur-multiplier 半群の完全正値性判定（Christensen–Evans 系、いずれも §7 で要実在確認）として**既知**。本提案の新規性はここには置かない。

**定理1（絶対検閲）— Exact（S3）.**
単一辺プロファイル `γ = c·(E_{jk}+E_{kj})`, c>0 は n≥3 で `𝒩` に属さない。よって「1つの sector コヒーレンスだけを切る」ideal counterfactual は、jump 数・対角 ancilla・埋め込み次元をいくら増やしても母集団保存 GKSL では実装できない。
*直観:* 脱位相は which-path 情報の取得である。j と k を区別する環境は、j,k を第三準位 l から区別せずにはいられない — `‖ζ_j−ζ_k‖>0` かつ `‖ζ_j−ζ_l‖=‖ζ_k−ζ_l‖=0` は矛盾（三角剛性）。一般判定は `√γ` の三角不等式を含む cnd 判定に一本化される。

**定理2（強度検閲と κ\*）— Exact な判定式、床の物理は Conditional.**
背景 generator 𝒢₀ のコヒーレンス減衰核 `K⁰`（減衰床補題により `K⁰_{jk} ≥ ½(Γ_out(j)+Γ_out(k))` の cnd 成分を含む）に検閲パターン δ を加えた合成が admissible ⟺ `Gram(K⁰ + κδ) ⪰ 0` ⟺ `κ ≤ κ*(K⁰,δ)`。κ\* は有理データなら厳密に計算できる。n=3・一様床 `K⁰=(1−δ_{jk})`・単一辺切断で **κ\*=3**（S6、厳密）。

**定理3候補（経路検閲）— Conditional（一般証明は Stage A の課題）.**
強散逸族 `A_Γ = ΓD + B` で背景床が Γ に線形比例するとき、κ\* も Γ に線形比例する。従って SMRT 経路 `κ=κ₀Γ^q` は **q>1 で漸近的に admissible でなくなる**: `q* = 1`。q>q\* の経路上の valuation `ν_S(q)` は ideal 量としては定義できても、その counterfactual を実装する介入族が存在しない。
*注意:* 背景床が Γ スケールしない slow sector（`D` の核上）では κ\* は O(1) に留まり、q\* = 0 となる。q\* は経路だけでなく **切断パターンと背景の対** の関数である。これは「q\* は普遍定数」ではないという意味で赤線9（universal codimension）型の過剰主張を最初から排除しておく。

**定義3（検閲ギャップ）— Conjecture（定式化のみ）.**
検閲された ideal プロファイル γ に対し、`Δ_cens(γ) = inf_{γ'∈𝒩, γ'≤結合条件} |ℛ[γ'] − ℛ^{ideal}[γ]|` を、宣言 functional Φ と観測窓上で定義する。錐距離 `dist(γ, 𝒩)` の下界から `Δ_cens > 0` の計算可能な下界が出る、が中心予想。

## 3. 理論固有現象

### 3.1-1 固有現象の定義

boxed 命題は §0。要約: **切断検閲（絶対・強度・経路の三層）と、それが強制する検閲ギャップ。**

### 3.1-2 非還元性の論拠（詳細は §4）

- 既知数学（Schoenberg/cnd）は補題2として**自白**した上で輸入する。新規性の重心は κ\*・q\*・Δ_cens という**応答理論の不変量**と、凍結コーパスの counterfactual 分類への遡及的帰結に置く。
- 検閲は周波数領域の解析性・受動性（CIRT の死因: Löwner/Nevanlinna–Pick 圏）と独立: 対象は応答関数の境界値ではなく **generator データの錐所属**。周波数依存性も解析接続も現れない。
- 資源下界型（rank 証明書、族D/A の次元計上）でもない: 錐は次元について閉じており、「budget を増やせば逃げられる」構造ではない。

### 3.1-3 観測可能量

1. **κ\* クロスオーバー（最短の観測痕）:** 切断強度 κ を掃引すると、`κ < κ*` では操作的応答が ideal-cut 予測（SMRT/EIT の閉形式）に一致し、`κ > κ*` では**いかなる実装を選んでも**系統的乖離が生じる。乖離の onset は κ\*（事前に厳密計算可能）。検出は数値（厳密有理演算 + 数値 GKSL）で即、実験では Λ系の ground-coherence 脱位相制御（磁場ノイズ注入）で原理的に可能。
2. **q\* 折れ:** SMRT の (q, ν) fan に「操作的定義域の壁」が q=q\* に立つ。壁の位置は背景床と切断パターンから予測できる。
3. **検閲パターン分類:** 与えられた sector 集合 𝕊 の切断が REALIZABLE / CENSORED のどちらかは有限の厳密判定（Gram の PSD 判定）で決まる。bipartition 切断は常に REALIZABLE、単一辺は n≥3 で常に CENSORED、中間パターンに非自明な境界がある（Z₆ 族で境界を有理区間に挟んだ、S4）。

有限サイズ・有限精度: 全て有限次元の代数判定であり、n=3 から見える。cancellation 依存の微小信号ではない（Gram 固有値の符号は開条件）。

### 3.1-4 反証条件

1. **実装の反例:** 母集団保存・time-local GKSL の枠内で、単一コヒーレンス切断を（ancilla 込みで）実装する構成が示されたら、補題1か2の適用条件が壊れており、理論は死ぬ。
2. **ギャップの不在:** `κ > κ*` の領域で、操作的応答が ideal-cut 予測に（実装をうまく選ぶと）いくらでも近づけることが示されたら、検閲ギャップ Δ_cens は空語になり、中心現象は「admissibility の教科書的注意」に降格する（stop condition 2）。
3. **文献での既出:** cnd 錐から κ\*・q\*・応答乖離までを介入 counterfactual の文脈で既に導いた論文が見つかったら死ぬ（§6）。

### 3.1-5 既存理論との一致領域

- bipartition 切断（凍結コーパスの主要な cut）は錐内部 → 既存の δχ_S・三分類・no-go はそのまま再現。
- `κ → 0` で全ての切断が admissible（錐は原点近傍で床に救済される）→ weak-cut 極限で凍結理論を完全回収。
- 実装制約を落とすと検閲消滅（S5）→ 凍結理論は「自由レート理論」としては無傷。

## 4. 非還元性の検討

**既知の一般機構:**

- **Schur multiplier / Schoenberg（既知数学）:** 補題2 = 既知。還元先ではなく土台として明示輸入。還元判定の対象は「κ\*・q\*・Δ_cens が既知の帰結か」。管見の限り、脱位相レートの CP 制約を **sector-cut counterfactual の操作的定義域**へ翻訳した文献はない — が、これは egress のある環境での文献監査（Stage 3）で確認するまで主張しない。
- **Zeno / adiabatic elimination / EP:** 検閲は摂動論的機構ではなく錐所属の代数的事実。強度・経路検閲のクロスオーバーは Zeno 縮約の形をとらない（κ\* は spectral gap でなく Gram の PSD 境界）。ただし q\* = 1 が Zeno onset と一致する模型がありうるので、判別 control（床を Γ 比例から外して κ\* だけ動かす）を Stage A に置く。
- **群同期（族C）:** 応答データに chart/gauge 構造がない。判定対象は generator の錐所属で、相対フレーム推定問題に写像する自然な方法がない — N/A を主張するが、赤チームには「γ プロファイルを hyperedge potential とみなす写像を試みよ」と明示的に依頼する。
- **FCS（族B）:** counting field も cumulant 階層も現れない。
- **HMM / 状態空間同定（族D）・process tensor（族E）:** 本提案は同定問題ではない。競合が「錐の外のプロファイルを持つ有効模型でデータを説明する」ことは可能だが、それは実装ではなく記述であり、検閲の主張（実装の非存在）とは衝突しない。ここを混同しないことが FRRG（提案21）との決定的な違い。
- **shared ancilla（族A）:** 補題1の対角性強制は系+対角 ancilla に拡張できる（対角代数上の埋め込み次元が増えるだけで錐は不変）。**非対角に作用する ancilla 媒介実装（系だけ見れば母集団保存に見える dilation）が time-local 性を保ったまま錐を破れるか**が最重要の逃げ道であり、Stage A の kill test A2 とする。破れたら死ぬ。

**Frozen-Theories:** 凍結3理論は切断レートを自由に置く。検閲はその前提の外にあり、凍結結果のどれからも導出されない（逆に、赤線1の「GKSL admissible に保つ」という一文の**内容**を初めて計算可能にする）。

**競合論文（§7 未確定）:** CIRT 監査で確定した族N（受動実現可能性）とは対象が異なる（インピーダンス境界値 vs generator 錐）。ただし「decoherence rates の CP 制約」そのもの（3準位系の positivity 制約の古典的研究を含む）は確実に先行研究があるため、**新規性は制約の存在ではなく応答理論への帰結**に限定して主張する。

**還元されてしまった場合:** ガイド §6.4 に記録し、番号25は欠番とする。
