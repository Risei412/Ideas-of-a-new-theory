# 計画19: 散逸応答の実現可能性錐理論（PRX投稿を見据えた新理論提案）

**作成日:** 2026-07-24
**位置づけ:** これは実行構成でも数値計画でもなく、SMRT（Sector-Master-Resolved-Theory）の
既存定理・認証済み数値証拠を土台として、理論を一段抽象化した新理論を提案する検討書である。
実行を強制するものではなく、理論構築・証明・査読前検証のための設計図として次の判断材料に供する。

**設計監査について（重要）:** 本設計は起草段階で敵対的監査を受け、初稿の中心的証明経路
（moment符号定値性による古典障害）は**反例により撤回した**（§1.1）。中心現象は
微調整依存の「昇格プレート」から、開条件ゆえに頑健な**逆行分枝（rising branch）**へ
移し、古典側no-goの証明経路はM行列レゾルベント正値性＋killing単調性＋walk-bracket分解
（R3）へ置換した。また本理論の証人が排除するのは「量子性」ではなく
**確率的レート動力学**である点を表現規律として固定した（§8）。

このリポジトリで認証済みの厳密結果を並べる。

すなわち**順問題**（モデル (L, c, p, S, G_S, path) → fan ν_S(q)）は閉じた定理体系になった。
一方、SMRT定理パッケージ自身が明示するように、**逆問題**——

> どの区分アフィン関数 ν(q) が、物理的に許容される動力学によって実現可能なのか

——は完全に未解決である（realizability分類は宣言された将来課題であり、
古典Markov vs 量子GKSL の比較定理はリポジトリ内に存在しない）。

**この逆問題には初等的だが決定的な入口がある。** 古典Markov生成子（Metzler行列）で、
介入 G_S が killing 型（対角・非負・S上支持）、プローブ源 c ≥ 0・読出し p ≥ 0
（成分ごと）とする。このとき A(s) = sI − Q + ΓD + κG_S は非特異M行列であり、
レゾルベントは成分ごとに非負、しかも killing を強めるほど各成分は単調に減る。ゆえに

$$R_S^{\mathrm{op}} = \chi_{\mathrm{full}} - \chi_{\mathrm{cut}}(\kappa) \;\ge\; 0,
\qquad \partial_\kappa R_S^{\mathrm{op}} \;\ge\; 0$$

が**点ごとに**成り立つ。経路 κ=κ₀Γ^q で q を上げることは（十分大きいΓで）κ を上げる
ことだから、正値量の単調性がそのまま指数に翻訳され、

$$\boxed{\text{古典（H1–H4）: } \nu_S(q;\kappa_0) \text{ は } q \text{ について非増加}}$$

が出る。ところが認証済みの5準位量子witnessのfanは **ν(1)=3 → ν(2)=4 と上昇する**。
この「逆行分枝」は、上の初等計算が禁じる振る舞いを量子コヒーレント散逸経路が
実現している、という一組の事実であり、本理論の出発点である。

## 1. 理論名と中心主張

**散逸応答の実現可能性錐理論**（Realizability Cone Theory of dissipative response, RCT）。

一言で：*実現可能なsector応答fanの集合は、動力学の物理クラスごとに異なる
「錐」（min-plus半加群）をなす。詳細釣合い古典 ⊆ 古典Markov ⊆ 量子GKSL の階層は
厳密に分離し、その分離は逆行分枝という単一の頑健な観測量に現れる。
fanの形そのものが、断層撮影なしに動力学クラスを反証する証人になる。*

中心対象は3つの実現可能fan集合：

$$\mathcal V^{\mathrm{DB}}_C \;\subseteq\; \mathcal V_C \;\subseteq\; \mathcal V_Q$$

（詳細釣合い古典鎖／一般古典Markov（Metzler）／量子GKSL、いずれも宣言interface
クラス＝killing型介入・固定source/readout・宣言経路族の下で定義する）。

### 1.1 撤回した証明経路：moment符号定値性

初稿設計では「古典鎖では拡大空間moment 𝔪_k = p̂†(D̂⁻¹B̂)^k D̂⁻¹ĉ の
path重みがすべて同符号なので完全相殺が起きない」を古典障害の中心に置いた。
**これは誤りであり撤回する。** 反例は自己ループである：

> B(z) = zI + M は対角挿入（z と遅いレート）を含むため、長さ k の walk のうち
> 自己ループを j 個含むものの符号は (−1)^(k−j) となり、実 z > 0 ですら
> 固定次数 k の moment 内で符号が混在する。z = iω では全対角挿入が複素になる。

余次元・障害の出所は「moment項の符号」ではなく、**組み上がったレゾルベントの
点ごとの正値性と、killingに対する点ごとの単調性**である（walk和を項別にではなく
bracket単位で評価する。§3 R3）。同時に、微調整（測度ゼロ）条件である
「面係数の完全相殺＝昇格プレート」を旗艦観測量にすることもやめ、
開条件で頑健な**逆行分枝**（2つの傾きの不等式）を旗艦に据える。

## 2. 創設の問い（未解決性・分野横断性）

**問い:** 「有限次元開放系のsector応答fanのうち、物理的に実現可能なものは何か。
実現可能集合は動力学の物理クラス（確率的レート動力学／コヒーレント散逸動力学／
その詳細釣合い成層）ごとに真に異なるか。異なるなら、その差はどの有限データから
証人可能か。」

前半はSMRTが明示的に残した逆問題（realizability分類）そのものであり未解決。
後半（クラス分離の証人化）は本理論の決定点である。分野横断先：

- **開放量子系の基礎**: fanという漸近不変量のレベルで「レート方程式で記述可能な系」
  と「コヒーレント散逸経路を要する系」が分離する。Markov近似の内部に、
  確率的か干渉的かの二分法が指数値として刻まれる。
- **量子情報・系同定**: 逆行分枝は指数値（離散）で読めるため、FCS/TUR型の
  不等式証人と違い校正ドリフトに頑健。「2つの傾きの比較」だけで
  レート方程式模型族を丸ごと反証できる——モデル個別のfitを経ない**模型クラス反証**。
- **正値システム制御理論**: 𝒱_C の特徴づけは正実現問題（positive realization
  problem）の漸近版であり、同分野で難問と知られる問題の新しい切り口になる。
  逆にM行列・正値LTI理論は本理論の補題群を供給する（引用必須、§5）。
- **確率熱力学・反応ネットワーク**: tropical簡約（dominant subsystem）は
  「古典では相殺が起きない」ことに暗黙に依存して成立している。R3はその暗黙の
  前提を定理化し、R4は**相殺こそがコヒーレンスの資金源**であることを示す。
  古典錐 𝒱_C の記述自体が反応網理論への新結果。
- **非エルミート物理**: 錐境界は非半単純（Jordan）成層であり、EP物理は
  「実現可能性錐の境界幾何」として再文脈化される（R6）。内部＝整数傾き、
  境界＝Puiseux分数傾き、という新しい大域像を与える。
- **分光学**: EIT–ATS認証（既存資産）が示した「機構ラベル ⊥ fan分類」に続き、
  本理論は第3の軸「実現可能クラス」を与える。観測fanが 𝒱_C の外にあれば、
  いかなる古典レート模型のfitも不要のまま干渉的経路の存在が結論できる。

### R1（厳密定理候補）鋭い複雑度定理
A₁ = ΓD + B、A₂ = A₁ + κG_S、r = rank G_S とすると、多重線形性より
det(A₂)・adj(A₂) の κ次数は ≤ r。ゆえに

- Q_S = det(A₁)det(A₂): deg_Γ ≤ 2N_resp、**deg_κ ≤ r**
- N_S = p†adj(A₁)c·det(A₂) − p†adj(A₂)c·det(A₁): deg_Γ ≤ 2N_resp−1、**deg_κ ≤ r**

d_q(P) = max_{(a,b)∈supp}(a+qb) はNewton多面体のsupport関数であり、q増加に伴い
最大化点の κ次数 b は非減少。よって各weighted次数の傾き変化は ≤ r 回、差である
ν_S の**正則breakpointは ≤ 2r**、傾きは κ次数の差なので **|ν′(q)| ≤ r**。
相殺はsupportを削るだけで頂点数を増やせない（頂点係数は単項 n_{ab}κ₀^b であり、
消えるのは n_{ab} ≡ 0 のときのみ）。孤立したκ₀特殊tie点は別勘定 O((Nr)²) だが
測度ゼロかつε摂動で消える。

**witness照合:** 5準位witnessは N_resp=4, r=2（Ĝ_{S34}=½diag(0,1,1,0)）⇒
上界: breakpoint ≤ 4・|傾き| ≤ 2。観測: breakpoint {1,2} の2個・傾き ±1。整合。

### R2（厳密）次元証人
R1の対偶。K個の正則breakpointを測れば r ≥ ⌈K/2⌉、傾きの大きさ s を測れば r ≥ s、
ν(0)=V を測れば N_resp ≥ V/2。**スケーリングデータのみから、参加準位数・介入rankの
下界が認証される。** prepare-and-measure型の凸幾何次元証人と相補的な、
動力学的・代数的次元証人である。

### R3（中心・厳密定理候補）古典単調性no-go
**仮定:**
- (H1) 有限古典（sub-）Markov生成子；源 c ≥ 0・読出し p ≥ 0（成分ごと；注入・占有型プローブ）
- (H2) 介入 G_S は対角・非負・S上支持のkilling型（利得は応答空間外へ；
  量子witnessのcut ½diag(0,1,1,0) と同型のクラスであり、比較は対称）
- (H3) Γスケール散逸は応答空間上で対角（sinkへの脱出；Γスケールの再流入なし）
- (H4) 全係数関数は実有理；窓 K 上の恒等消滅が実半直線 s>0 上の恒等消滅と同値
  （実有理データなら恒等定理より自動。AC/複素プローブはこの経由で扱う：
  応答は点ごとに複素でも係数関数は実有理なので、完全相殺は正値性が禁じる実半直線上でも
  成り立たねばならず、矛盾する）

**主張:**
- (a) R_S^op ≥ 0 かつ κ について非減少（M行列レゾルベント正値性＋killing単調性）
- (b) **ν_S(q;κ₀) は q について非増加**（全 κ₀ > 0）
- (c) tropical walk上界: ν_S(q) ≤ min_{α: S経由walk} ω_α(q)。
  各bracket w_α(0) − w_α(κ) ≥ 0 単独が R_S^op の下界を与えるため、
  無限walk和の交換も genericity も不要。退化レート模型でも有効
- (d) ゆえに**逆行分枝を持つfan、またはS経由最小walk重みを超えるプレートを持つfanは、
  クラスH1–H4の古典動力学ではいかなる有限次元でも実現不可能**

### R4（決定点）実現可能性ギャップ
R3(d) ＋ 既存認証済み5準位witness（Phase N gates全PASS、CP/TP監査済み）から直ちに

$$\nu_{\mathrm{witness}}(q) \in \mathcal V^Q_5 \setminus \mathcal V_C\quad(\text{古典側は全次元})$$

つまりギャップは次元固定の比較ではなく**古典側次元非依存**で開く。付随補題：

- **Λ/rank-1最小性補題**: 3準位Λ（中間コヒーレンス1個・rank-1対角cut）では
  S経由最小walkが一意で、その重みは結合の非零単項式。z依存の自己ループ着衣では
  恒等相殺できず、昇格は不可能（短い証明で確定できる）
- 4準位・rank≤2の全ケースは計算的認証（Gate C4）で潰す。それまで最小次元は「≤5」と表記

**操作的帰結（証人化）:** 逆行分枝の検出は「2つの区間で傾きを測り比較する」だけであり、
指数値（離散・整数制約つき）で読めるため校正・ドリフトに頑健。断層撮影も
lineshape fitも個別模型のfitも不要のまま、**確率的レート動力学の模型族全体を反証する**。
排除されるのは「古典性」ではない（§8）。

### R7（証人主張の必要条件）有限窓頑健性
昇格プレート（ν=4枝）は面係数の恒等相殺という余次元≥1条件に依り、ε摂動は
O(ε)係数を再生して観測指数をクロスオーバー Γ*(ε) 〜 ε^(−1/Δ)（Δ=相殺面と生存面の
重み差）以遠で3へ戻す。定量定理「窓指数は Γ ∈ [Γ₀, c·ε^(−1/Δ)] で昇格値に一致」を
証明しない限り、プレートは厳密演算の産物であり測定不能である。
一方**逆行分枝（区間[1,2]の傾き+1）はsupport幾何の開条件であり頑健**。
同じ定理を有限次元Markov埋め込みされたメモリカーネルに適用すれば、
**ε非Markov摂動に対する証人の安定性**が同時に従う。

### R8（新規・高利得）min-plus閉性と補間
並列合成はfanのmin-plus和、直列減衰鎖は整数シフトを与える（generic無相殺のmin則）。
ゆえに各 𝒱 はmin-plus半加群をなす。目標定理：**R1の制約（区分アフィン・整数傾き・
|傾き|≤r・breakpoint≤2r）と整合する任意のfanは、ある有限 n で構成的に実現可能**。
R1（上から）とR8（下から）で錐を挟み、実現可能集合の完全記述に至る。

### R9（条件付き候補）詳細釣合い成層
可逆鎖の伝達関数はStieltjes構造を持つ。予想：killing-cut可逆fanは正確に
ν(q) = ν_ideal + max(0, 1−q) の2区分形に退化する。成立すれば
𝒱^DB_C ⊊ 𝒱_C ⊊ 𝒱_Q の3層すべてが実例つきで分離する。

### R6（予想）境界成層
錐境界には非半単純（Jordanブロック）成層があり、そこではPuiseux分数傾きが現れる。
内部＝整数傾き／境界＝分数傾き。SMRTが「宣言された閉パッケージの外」と明示した
非半単純領域を、錐の境界幾何として回収する。EP文献との接続はここに限定する。

### R5（remark）決定可能性
固定 n でのfan所属はGKSL/CP制約が半代数的なのでTarski–Seidenbergにより決定可能。
真だが標準的・二重指数的で実効構造を与えないため、本理論の主張には数えない。

### ユーザー要求3基準への明示的応答
1. **未解決性・分野横断性**: 中心の問いはSMRTが明示的に開いたまま残した逆問題
   （realizability分類）＋文献に存在しない古典/量子fan比較定理。影響先は
   開放系基礎・量子情報・正値システム制御・確率熱力学/反応網・非エルミート・分光学の6分野（§2）。
2. **固有現象**: 逆行分枝は (i) Zenoに還元不可（Zeno narrowingは単項傾きを与えるだけで
   区間間の傾き反転を与えない）、(ii) Fanoに還元不可（Fanoは線形の符号構造であり
   Γ-grading間の不等式でない）、(iii) EP理論に還元不可（縮退不要・スペクトルでなく
   応答差の tropical 幾何）、(iv) tropical反応網簡約に還元不可
   （同理論は「古典では相殺しない」ことを暗黙の前提とするのであって、
   相殺の可否がクラスを分離するという命題はその外にある）、
   (v) 正値システム理論に還元不可（補題は既知でも、二スケールfan対象・walk-tropical上界・
