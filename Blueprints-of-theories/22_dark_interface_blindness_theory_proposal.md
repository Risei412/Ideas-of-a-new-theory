# 計画22: 暗界面盲点理論（Dark-Interface Blindness Theory / DIBT）

## 一行サマリ

初期状態と読出しに対して**暗**なセクターに台を持つ介入対は、脱出深さ `β_esc` 未満の
全 protocol でトランスクリプトが**厳密に**一致する。この盲点は微調整ではなく
**protocol data（台の幾何）で保護された開集合**であり、脱出時のギャップは
rank 制約つきの因子化則に従う。これにより「資源制限観測者は分離できない」ことが
**仮説検定の converse として定理化できる** — 文献監査が P0-2 に要求した
「cancellation-protected な例外集合上の、凍結資源内の下界」の理論本体を与える。

**作成日:** 2026-07-26
**位置づけ:** ガイド §6.1 **P0-2「Resource-bounded mechanism separation」**
（壊す仮定：unrestricted representation criterion）の理論設計図。

**判定:** PRX候補として探索する価値がある。ただし新規性の重心は

## 0. 結論

中心の問いは次の一つである。

> 有限次元 GKSL 系への2つのセクター介入 `𝒢_S`, `𝒢'_S` が、
> **固定された protocol class（深さ・アルファベット・shot 数）の下で
> 統計的に分離不可能となるのはいつか。**
> その盲点はどこまで物理的（CPTP）に実現可能で、どの深さ・どの資源で必ず脱出できるか。

理論固有現象を次のように置く。

> ### 【固有現象】認証盲点と脱出深さ（Certified Blind Spot ／ 認証盲点、Escape Depth ／ 脱出深さ）
>
> 初期状態 `ρ₀` と読出し `p†` を固定する。介入差 `Δ_S := 𝒢_S − 𝒢'_S` が、
> `ρ₀` から深さ `j` 以内に到達可能な空間 `Reach_j` と、`p†` から深さ `i` 以内に
> 観測可能な空間 `Obs_i` に対して
>
> $$\boxed{\ \beta_{\rm esc} \;:=\; \min\{\, i+j+2 \;:\; \mathrm{Obs}_i \,\Delta_S\, \mathrm{Reach}_j \neq 0 \,\}\ }$$
>
> を定めるとき、**深さ `< β_esc` の全 protocol でトランスクリプト分布は厳密に一致し**
> （盲点）、深さ `β_esc` で初めて分離する（脱出）。脱出ギャップは
>
> $$G_{xy} \;=\; (\text{読出し側因子})_x \cdot (\text{到達側因子})_y, \qquad \mathrm{rank}\,G \le \mathrm{rank}\,\Delta_S$$
>
> という**間隙因子化則（gap factorization law ／ 間隙因子化則）**に従う。
>
> **鍵となる性質:** この盲点は係数の微調整（measure-zero の相殺）ではなく、
> **`Δ_S` の台が `(ρ₀, p†)`-暗セクターに含まれるという protocol data で保護される**。
> 台条件を保つ任意の摂動に対して盲点は**厳密に**保たれる — 開集合上の現象である。
> 文献監査の用語では、これが「cancellation-protected な例外集合」の明示的構成である。

この上に立てる主張は3層になる。

1. **no-go（分離不可能性定理）** — 深さ `< β_esc` に制限された観測者は、
   **shot 数無制限・適応的設計・任意の競合族（A〜F）を許しても**分離できない
   （KL 恒等的にゼロ）。漏れ `η` がある現実版では、二点法 converse により
   shot 下界 `N ≳ c/η²` が出る。**ガイドの gate I（情報理論的下界）を、
   殺される側ではなく主張する側として使う。**
2. **分類（盲点実現可能性）** — どの `(β_esc, rank Δ_S, dim)` の組が
   CPTP／GKSL admissible な介入対で実現可能か。古典 Markov では実現可能だが
   量子 GKSL では禁止される組（またはその逆）があれば、それが最強の理論固有結果になる。
3. **予言（因子化則）** — 脱出ギャップの rank 制約は held-out protocol の
   ギャップを少数の測定から**盲予測**させる。逆設計（狙った protocol だけで
   見える／見えない介入対の構成）も同じ式から出る。

### 1.3 却下済み候補の死因への直接応答（本提案の存在理由）

§6.5 の「Matched operational equivalence」は、**数値最適化で**トランスクリプトを
`D_TV ≤ 1.4×10⁻¹⁶` まで一致させた matched pair だった。また §6.4 の
「resource-separation matched pair」は **Bayes 仮説検定・非線形 OED への還元**で死んだ。
本提案は両方の死因を構造で回避する。

1. **一致が最適化ではなく台構造による厳密恒等式** — 盲点上では calibration 尤度が
   文字どおり同一関数になる。`10⁻¹⁶` の数値一致を「摂動でズレないか」と疑う余地がない。
2. **仮説検定への還元が、殺す側から主張する側に変わる** — matched pair 候補は
   「Bayes 検定で分離できてしまう」形で死んだ。盲点上では calibration class 内の
   **どんな検定も検出力が厳密にゼロ**であり、仮説検定の枠組み自体が no-go の証明道具になる。
   同様に family F（能動的実験設計）は、盲点上で期待情報利得が恒等的にゼロとなるため、
   **適応性が証明可能に無力**である。
3. **chart／gauge 構造が存在しない** — §6.5 の4候補の共通死因
   （pairwise relative-chart 因子化 `G_ij = X_j X_i^{-1}`、および Duncan–Kileel の
   higher-order synchronization）は、witness が群値データに写ることに依存する。
   本提案の witness は語確率テンソルのギャップと rank であり、
   相対フレームがない。`context-pack.md` §6.2(c) の規定により族Cは **N/A**。
4. **「維持できない表現」リストとの照合** — 監査が禁じた
   「pairwise data が一致しても triple data が異なる」は、genericity の反例（Huang 2016）で
   殺される主張だった。本提案の主張は「深さ2一致・深さ3分裂」**ではなく**、
   (i) 例外集合への帰属の**記号的証明書**、(ii) その集合が protocol data で保護された
   **正次元 stratum** であること、(iii) その上での**凍結資源内 shot 下界**、の3点セットである。
   これは監査文書が「維持できない表現」の代わりに要求した形そのものである。

## 2. 理論の定式化

### 2.1 型の宣言（ガイド §2）

- **型:** **(B) 数学的定理型**（no-go＋分類）を主、**(A) 現象論**（因子化則という観測可能予言）を従とする **(D) 統合型**。
- **対象系:** 有限次元・開放系・量子（time-local GKSL）。古典 labeled Markov 模型は
  比較対象・反例供給源として明示的に併置する（分類定理の片側を担う）。
- **対象スケール:** protocol 深さ `≤ 4`・凍結 shot 予算（`context-pack.md` §6.4）の有限資源域。
  漸近極限は使わない。**極限交換問題（赤線10）が原理的に発生しない**のは本提案の利点である。
- **想定読者:** 量子情報（系同定・メトロロジー）、開放量子系、統計的推測、量子光学。

### 2.2 記法（ガイド §5.3 の衝突回避）

| 記号 | 意味 | 衝突回避の注記 |
|---|---|---|
| `𝒢_S, 𝒢'_S` | sector 介入生成子の対 | RISEI/SMRT と整合（そのまま使用可） |
| `Δ_S := 𝒢_S − 𝒢'_S` | 介入差 superoperator | RISEI の `Δ_prot` と区別するため必ず添字 `S` を付す |
| `𝒮_dark` | `(ρ₀, p†)`-暗セクター | 新規記号 |
| `Reach_j` / `Obs_i` | 深さ `j` 到達可能空間 ／ 深さ `i` 観測可能空間 | Krylov フィルトレーション。衝突記号 `K`・`R` を避けて英単語で書く |
| `β_esc` | 脱出深さ | EIT の `β = \|Ω_c\|²/4` と衝突するため**必ず添字 esc 付き**で書く |
| `η_leak` | 暗性の漏れ（初期状態・読出しの暗セクター重なり） | 新規記号 |
| `G_{xy}` | 脱出ギャップ行列 | EIT の resolvent `G` と衝突するため必ず添字付き成分表記 |
| `r_gap` | `rank Δ_S`（間隙 rank） | 新規記号 |

### 2.3 定義

**定義 2.1（暗セクター）**
固定された `ρ₀` と `p†` に対し、sector `S` が **dark** であるとは、
`Reach_0 = span{ρ₀}` が `S` に重ならず、かつ `Obs_0 = span{p†}` が `S` 上の作用を
見ないことをいう。深さつきの一般化として、`Reach_j`（全介入文字と自由発展で生成される
Krylov フィルトレーション）と `Obs_i` を用いる。

**定義 2.2（盲点と脱出深さ）**
介入対 `(𝒢_S, 𝒢'_S)` の**脱出深さ**を §0 の boxed 式で定める。
深さ `< β_esc` の全 protocol（介入文字列と読出しの任意の組合せ、両順序含む）で
トランスクリプト分布が一致するとき、対は **blind at depth `< β_esc`** であるという。

**定義 2.3（認証盲点）**
次の3点が揃った盲点を**認証盲点**と呼ぶ。
(i) calibration class 上の一致の**記号的証明書**（exact arithmetic、SMRT の
Krylov exact-zero 機構を使用）、(ii) 脱出 protocol での**認証された margin**
（P0 仕様の `σ` 判定と同形式）、(iii) 漏れ `η_leak` を含む**shot 下界**。

### 2.4 主張（logical status を明示する）

> **主張 B1（次数つき盲点判定 / status: Exact — ただし本質的に既知の機構）**
> 深さ `< β_esc` の全 protocol でトランスクリプトは厳密に一致し、
> 一般の係数では深さ `β_esc` で分離する。判定は有限次元線形代数で決定可能。
>
> **これは新規結果として数えない。** 単一文字なら Markov パラメータの moment matching
> （部分実現理論）、多文字なら非可換有理級数の実現理論（Fliess／Schützenberger）の
> 言い換えである可能性が高い（§4.1 の kill test A1）。B1 の役割は土台であって新規性ではない。
> 数値確認済み（§3.3：深さ `< β_esc` のギャップは浮動小数点ゼロではなく代数的ゼロ）。

> **主張 B2（間隙因子化則 / status: Exact（構成 class 内）→ 一般化は要証明）**
> 脱出深さでのギャップは `Obs_i Δ_S Reach_j` の最初の非零 pairing を通して因子化し、
> ギャップ行列の rank は `r_gap = rank Δ_S` で抑えられる。
> `r_gap = 1` なら完全分離形 `G_{xy} = α_x β_y` になる。
>
> 数値確認済み（§3.3：rank-1 構成でギャップ行列の第2特異値が `10⁻¹⁹`、
> 実測ギャップとの一致 `7×10⁻¹⁸`）。**予言としての価値:** 少数の脱出測定から
> 残り全ての held-out ギャップが予測される（盲予測 protocol、§5.2）。

> **主張 B3（盲点の物理性 / status: Conjecture — 本提案の中心的な未証明命題）**
> GKSL admissible な介入対で、任意の指定 `(β_esc, r_gap)`（次元で許される範囲）を
> 実現する構成が存在する。特に、trace 保存が `⟨⟨I| Δ_S = 0` を**自動的に**与えるため、
> 量子側では読出し側零条件の一部が構造的に無償で手に入る。
> さらに **CPTP が古典 Markov では実現可能な `(β_esc, r_gap, dim)` の組を禁止する
> （またはその逆）なら、それが本理論の最強の固有結果になる**（盲点実現可能性ギャップ）。
>
> 古典側の明示構成は完了（§3.3）。量子 GKSL 側の明示構成は Stage A2。
> 実現可能性ギャップの存否は完全に未解決 — **これが「新しい問い」の本体である。**

> **主張 B4（漏れ暗性ショット下界 / status: Conditional theorem — 証明経路は標準的）**
> 漏れ `η_leak` の下で、深さ `< β_esc` に制限された任意の観測者
> （適応的設計・任意の凍結競合族を含む）が誤り確率 `≤ α` で介入対を分離するには
>
> $$N \;\gtrsim\; \frac{c(\alpha)}{\eta_{\rm leak}^2\, \|\Delta_S\|^2}$$
>
> shots が必要である。`η_leak = 0` では分離不可能（KL 恒等ゼロ）。
>
> 証明経路は gate I の二点法そのもの（hard pair は本理論が明示構成する）。
> 数値確認済み（§3.3：深さ `≤ 2` の最大ギャップが `η_leak` に厳密に比例、係数 0.0070）。
> **注意:** 下界自体の証明技術は標準的であり、新規性は hard pair の
> **物理的（GKSL・protocol data 保護）構成**に置く。

> **主張 B5（競合族の証明可能盲目性 / status: Conjecture — 定式化に注意を要する）**
> 盲点上では calibration 尤度が介入対の交換に対して厳密対称なので、
> calibration のみから学習するいかなる凍結競合族（A〜F）も、held-out ギャップの
> **符号・パターン**を偶然以上に予測できない。
>
> ただし prior の非対称性で「予測」する退化ケースを排除する定式化
> （minimax か、対称 prior 制約か）を凍結する必要がある。Stage B3。

| 3 | 4.63×10⁻⁴ |
| 4 | 2.62×10⁻⁴ |

深さ ≤2 のゼロは浮動小数点の偶然ではない：端位置の `Δ` は台条件で必ず消える（代数的恒等式）。

**(2) 脱出深さの設計可能性（2段ゲート模型 `n=6`、設計 `β_esc=4`）**

暗セクターへ gateway 状態経由でしか入れず、gateway へは特定の文字でしか入れない構造：
深さ 1–3 が `≤ 10⁻¹⁶`、深さ4で `1.55×10⁻⁵` に跳ぶ。最大ギャップ語 `(2,1,0,1)` は
予測パターン（先頭 = gateway ポンプ文字、3文字目 = 介入文字）に一致。
**`β_esc` は到達グラフの設計で自由に動かせる。**

**(3) 間隙因子化則**

rank-1 摂動でギャップ行列の特異値は `(9.05×10⁻⁴, 1.7×10⁻¹⁹, 6.3×10⁻²⁰)` — rank 1 が厳密に成立。
実測の深さ3ギャップとの最大差 `7.3×10⁻¹⁸`。

**(4) destruction control（ガイド §4.4-7）**

- 初期分布に暗セクター漏れ `η_leak ∈ {10⁻², 10⁻³, 10⁻⁴}` を入れると、
  深さ ≤2 の最大ギャップは `0.0070 × η_leak` に**厳密に比例**して現れる（B4 の前提を直接支持）。
- 右零条件 `v^T 1 = 0` を壊すと深さ2で `1.4×10⁻³` のギャップが即座に出る。

> ⚠️ **このスモークは古典模型である。** 量子 GKSL 版（B3）は未構成であり、
> `depth` の物理的実体（pulse 数）・観測窓・weak probe との整合も未検証。
> logical status は Exact（構成 class 内恒等式）＋ Model-specific observation に留まる。

### 3.4 反証条件

1. **B3 の実現可能性ギャップが空** — 古典で実現可能な `(β_esc, r_gap, dim)` が量子でも
   常に実現可能（かつ逆も）なら、分類定理は「両側同じ」という退屈な答えになり、
   理論の最強部分が消える。no-go と因子化則だけが残り、PRL/PRA 型へ降格。
2. **因子化則の破れ** — 一般の GKSL 構成で脱出ギャップの rank が `r_gap` を超える例が
   見つかれば B2 の一般化は撤回（構成 class 限定の命題に縮小）。
3. **凍結競合族が盲点を「学習」する** — B5 の対称性論証に穴があり、いずれかの族が
   calibration のみから held-out ギャップのパターンを有意に予測したら、no-go 全体を撤回。
4. **既存定理の発見** — 脱出深さの分類・因子化則・物理実現可能性が
   実現理論／HMM 等価性理論の既存文献に実質的に含まれていたら（§4.1 A1）、
   本提案は「既知理論の物理への翻訳」に格下げされる。

### 3.5 既存理論との一致領域（sanity check）

- `β_esc ≤ 2`（暗セクターなし）で generic 同定可能性（Huang 2016）の世界に戻る。
- `η_leak = O(1)` で盲点は消え、標準的な系同定・OED が有効になる。
- EIT 極限：control field off の dark state 内介入は probe 応答に現れない
  （凍結 EIT 理論の dark-state 不可視性と整合）。control field を入れることが
  「脱出 protocol」に対応する — 凍結理論の go/no-go 判定と接続する（§5.3）。

## 4. 非還元性の検討

**方針宣言:** 本提案は §6.4 の教訓（現象を作ってから還元監査する順序の失敗）を踏まえ、
**還元される部分を先に自白する**。その上で、残る新規性がどこにあるかを特定する。

### 4.1 【自白】実現理論・部分実現・非可換有理級数（最大の既知部分）

- B1（次数つき盲点判定）は、線形系では Markov パラメータの moment matching
  （部分実現理論：Kalman、Gragg–Lindquist）、多文字では非可換形式冪級数の
  有理実現理論（Schützenberger、Fliess）の圏内にある可能性が**高い**。
  ガイド §6.3 の解析的 kill gate（Krylov／Kalman）は、まさにこの機構を
  候補を殺す道具として列挙している。
- **本提案の立場:** これを争わない。B1 が既知でも理論は死なない —
  凍結 EIT 理論が Schur complement（既知数学）の上に新しい分類問題を立てて
  生き残ったのと同じ構造を狙う。**新規性を置く場所は次の3点に限定する:**
  (i) **盲点実現可能性の分類**（B3：CPTP が課す制約。実現理論は正値性を扱わない）、
  (ii) **物理的に保護された hard pair による shot 下界**（B4：統計の定理と
  物理の構成の接合）、(iii) **間隙因子化則の held-out 盲予測**（B2：predictive surplus）。
- **kill test A1:** 非可換実現理論・HMM 等価性理論（Ito–Amari–Kobayashi 型の
  有限等価性判定）・部分実現の文献で、(i)〜(iii) に対応する結果の有無を赤チームに照合させる。
  (i) が既知なら本提案は死ぬ。(ii)(iii) のみ既知なら大幅縮小。

### 4.2 HMM 学習困難性（Mossel–Roch 型 parity 構成）

- HMM 学習の下界文献は「低次 moment が情報を持たない」hard instance
  （parity 型）を使う。**本提案の盲点と同じ精神**であり、最も危険な近接分野。
- **主張しうる差分（未確立）:** あちらは学習（模型推定）の計算量・サンプル下界、
  こちらは**2つの物理的介入の分離**という検定問題であり、hard pair が
  GKSL admissible・sector 介入・protocol data 保護という物理制約を満たす。
  また目的が下界の存在ではなく**分類（どの盲点が物理的か）**にある。
- **kill test A1':** parity 構成が暗セクター構成の特殊例として書けるか、
  逆に本構成が parity 構成に写るかを赤チームで検査。

### 4.3 特異統計模型（Watanabe）・古典的非同定可能性・family L（サンプル下界文献）

- Fisher 情報が退化する特異部分集合の理論は確立している。本提案の盲点は
  Fisher 退化より強い（**KL が恒等的にゼロ**の部分多様体）が、概念的には連続。
- family L（`literature-audit-addendum.md` の sample-complexity 下界26件）との差分は
  §4.2 と同じ形で主張する。**監査済み文献との照合を Stage A1 に含める。**

### 4.4 競合6族との関係（本提案では役割が変わる）

本提案の主張は「現象が族 X に表現できない」型ではない。族 A〜F は**表現の候補**ではなく
**観測者の候補**であり、no-go（B4/B5）の quantifier の定義域である。それでも各族について
検査すべきことは残る：

| 族 | 検査事項 | 現状 |
|---|---|---|
| A（hidden GKSL）・D（HMM） | 盲点対は族の内部にいる（両模型とも小さい HMM）。容量分離は**主張しない**。族が calibration から held-out ギャップを予測できないこと（B5）のみ主張 | B5 未証明 |
| B（FCS） | tilted 生成子も盲点上では両介入で同一 — FCS は盲目性を共有する。検査：counting field が暗性を破る経路がないか | 未検査 |

| G（解析 gate） | Krylov／Kalman はまさに B1 の機構。**還元ではなく土台**として明示 | §4.1 で自白済み |

### 4.5 却下リスト（§6.4）・「惜しかった」4候補（§6.5）との照合

- 特に「pairwise 因子化への還元」で死んだ4候補と異なり、本 witness は群値データに
  写る構造を持たない。higher-order synchronization（Duncan–Kileel）にも
